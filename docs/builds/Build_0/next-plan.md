# 4팀 빌드 0 다음 빌드 계획

## 다음 빌드 목표
-  멀티 플레이로 본부에서 볼 수 있는 범인 데이터로 NPC들 사이에 있는 범인 한명을 스캔 및 검거 과정을 거쳐서 본부로 넘기는 1사이클 완성

### 상호작용 시스템

- IInteractable 인터페이스 정의
- 1인칭 손 및 장착 아이템 표현
- 플레이어 레이캐스트 기반 타겟팅 (전방 상호작용 대상 감지)
- 아이템 사용(Use)에 타겟 전달되도록 구조 변경
- 스캐너 — 레이캐스트로 감지한 실제 대상에 작동하도록 전환
- 수갑 — 레이캐스트로 감지한 실제 대상에 작동하도록 전환

### NPC

NPC 체포(Captured) 상태 구현
NPC 스포너 — 필드에 다수 NPC 배치
범인 랜덤 배정 및 표시 데이터 오염(위장) 로직

### 본부(HQ)

체포된 NPC 본부 인계 상호작용
진범 판정 로직 (실제 데이터 대조)
CCTV 시스템 본부 통합 (상호작용 기반)

### UI

용의자 스캔 데이터 화면 출력

### 게임 진행 관리

라운드 매니저 (시작 → 진행 → 종료)

### 플레이어 표현/비주얼

이동 애니메이션 적용

### 인벤토리/아이템

마우스 휠 아이템 전환
아이템 프리팹화
게임 시작 시 기본 장비 지급

### 통합 검증

데모 씬에 전체 요소 배치
스캔→체포→인계→판정 풀 사이클 플레이 테스트
