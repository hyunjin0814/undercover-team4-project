# 4팀 빌드 4 다음 빌드 계획

## 다음 빌드 목표

- 난이도 상승·세이브/로드를 구현해서 **단판 → 여러 회차 진행 구조**로 확장  
  \+ **플레이어 표현**(감정표현·커스터마이징)과 **콘텐츠 추가**(아이템·돌발 이벤트)

### 진행 구조 / 난이도 상승

- **회차(일차) 진행 구조 도입** — 라운드 종료 → 정산 → 다음 회차 시작 루프  
- **난이도 커브 설계** — 회차가 오를수록 조정할 수치 선정  
  - 후보: 목표 금액 ↑ / NPC 수·구성비(시민:용의자) / 위조 난이도(문양 종류 증가) / 돌발 이벤트 빈도 증가

### 세이브/로드

- **저장 범위 확정이 선행**  
- **세션 저장**(진행 중인 판) — 호스트 권한 저장/복원  
  - 호스트만 저장·불러오기, 나머지는 재접속으로 합류하는 방식  
- **로컬 저장**(계정 단위) — 커스터마이징 외형, 조작·오디오 설정

### 맵

- **맵 제작** — 테마가 다른 맵을 제작하여 맵에 따라 이벤트를 다르게 배치

### NPC

- **NPC 상태 분할**  
  - 기절과 죽음 상태 분리  
  - 남은 체력이 20%면 기절, 0%면 죽음 상태 적용  
- **이동 폴리싱**  
  - 문 통과·좁은 골목 끼임, 서로 밀리는 문제(NavMeshObstacle / Avoidance Priority 정리)  
  - 정지-재출발 시 미끄러짐, 회전 스냅

### 돌발 이벤트 추가

- 플레이어 개인 자금을 뺏는 소매치기 이벤트  
- 차량 급발진으로 생기는 교통사고 이벤트

### 현상금 시스템 수정

- 기절한 NPC와 죽은 NPC의 현상금을 다르게 적용

### 아이템 추가

- 맵의 일정 영역을 스캔해서 범인이 있는지 없는지를 알려주는 본부 설치형 아이템
