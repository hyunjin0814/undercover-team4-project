# 빌드 4 빌드 노트

---

## 시작 방법 (세션 접속)

1. 게임 실행 → 타이틀 화면에서 자동/수동 로그인 (UGS 익명 인증). 계정을 연동해 두면 **다른 기기에서도 같은 닉네임으로 접속**된다. 화면 언어는 설정 창에서 **한국어 / English** 중 고른다 (즉시 반영)  
2. **호스트**: `세션 만들기 (Create)` → 생성된 Join 코드를 팀원에게 공유  
3. **참가자**: Join 코드 입력 → `코드로 참가 (Join)`  
4. **로비** — 접속자 목록에서 서로의 닉네임·방장·발화 상태를 확인하고, 호스트가 `시작` 버튼을 누르면 게임 루프 시작. (상점으로 이동)

## 게임 진행

1. **상점** — 팀 정산금으로 아이템을 구매한다. 소지형(스캐너·밧줄 등)과 **설치형**(신호 해석기·유치장 사이렌 버튼)을 팔고, 구매품은 팀 소유로 등록되어 **다음 라운드부터 본부 택배 지점으로 배달**된다. 호스트가 `출동 게이트`에 E를 누르면 게임 맵으로 출발  
2. **게임 맵** — 로딩 화면이 걷히면 **참가자 전원이 준비를 보고할 때까지 대기**한 뒤 라운드가 시작된다 (NPC 스폰 → 진범 배정 → 수배 리스트 게시). 기본 지급품(스캐너·밧줄·진압봉)은 게임 씬 진입 시 지급되고, 구매품은 본부 택배 지점에 놓인다.  
3. **라운드 진행** — 제한시간 안에 목표 금액만큼 벌어들인다. 진행도는 *지금 감옥에 잡아둔 대상들의 현상금의 합이다.* 탈옥하거나 반출하면 진행도도 줄어든다. 진행도는 **본부 내 게시판**에서 볼 수 있다.  
4. **검거 판정 장소는 감옥** — 무력화한 대상을 밧줄로 묶어 감옥까지 끌고 간 뒤, **문 옆 판정 버튼에 E**를 누르면 검거/오검거 판정이 나고 통과한 대상만 감옥 안으로 들어간다 (본부 인계존은 없어졌다)  
5. 목표를 채우면 **본부의 라운드 종료 버튼이 활성화**된다. 팀이 원할 때 눌러 끝내거나, 더 벌고 싶으면 제한시간까지 계속 수사한다 (안 눌러도 목표를 넘겨 있으면 성공)  
6. 라운드가 끝나면 정산 화면을 거쳐 다시 상점으로 복귀 — 세션이 유지된 채 다음 라운드로 이어짐. 정산 화면에는 **팀 자금과 내 개인 몫이 함께** 표시된다

## 핵심 플레이 루프

1. 본부에서만 볼 수 있는 몽타주 정보를 현장에 알림  
2. 현장은 외형 필터링 이후 스캐너로 NPC의 정보를 확인  
3. 위조범 혹은 범인이면 타격하여 체력 0으로 만들고 밧줄로 체포  
4. 체포한 범인을 데려와서 본부 옆의 감옥 컨테이너의 판정 버튼을 누르면 판정

## 구현된 기능

> 지난 빌드(주간 빌드 1·2·3)에서 이미 있던 기능과, 이번 빌드(주간 빌드 4)에 추가된 기능을 나눠 표기.

### 지난 빌드(빌드 1·2·3)에서 구현된 것 — 프로토타입 완성까지

**네트워크 / 세션 / 계정**

- UGS 익명 로그인, Relay 기반 세션 생성·코드 참가 (최대 6인), Vivox 음성 채팅(V 홀드 무전 \+ 근접 음성)  
- 타이틀 → 로비 → 상점 ↔ 게임 맵 루프, 씬 전환 로딩 화면, ESC 일시정지 패널·나가기 확인창  
- 로비 접속자 목록(닉네임·방장·음성 상태), 닉네임 영속 저장, 계정 연동, 세션 나가기와 로그아웃 분리

**게임 루프 / 라운드**

- 라운드 목표 \= **목표 금액**(현상금 라운드마다 랜덤), 진행도는 유치장 점유 현상금 합  
- 본부 라운드 종료 버튼, 라운드 정산 화면, 팀 공용 자금, 상점(진열대 조준 → 정보 카드 → E로 구매 → 다음 라운드 본부 택배 배달)  
- 아이템은 게임 씬 진입 시 지급 → 라운드 종료 시 회수, 라운드 시작 준비 단계(NPC 스폰 완료 후 시작)  
- 설정 창(감도·마스터/음성 음량)

**현장 (수사 · 검거)**

- 검거 수단은 **밧줄** — 무력화된 대상만 묶어 끌고 다닌다. 여러 명 동시 끌기, NPC 무게에 따른 이동 페널티, 여럿이 함께 끌면 완화  
- 진압봉 근접 타격 \+ NPC 체력 시스템(0이면 기절), 테이저(쿨다운 채널링 게이지·아군 오사)  
- 스캐너(배터리 소모 \+ 본부 충전), 스캔 정보 월드 카드와 미스캔 `??` 마스킹  
- 반응 트리거는 **스캔·피격** — 의심받으면 도주, 순응형은 맞으면 도주/저항  
- 검거·오검거 판정 배너, 위조범 즉결 처리, 오검거 페널티(추격·포획·호송), 유치장 수감

**본부 (관제)**

- CCTV(화면 전환·전원 버튼, 미니맵 마커, 채널 라벨), 수배 리스트(몽타주), 시민 인명부 \+ 이름 위조, 외형 대조 6축, 세력 문양 대조판, 신호 해석기  
- 제보 전화 — 받으면 예비 용의자 1명이 수배 리스트에 공개

**플레이어 / NPC**

- 시민 FSM(배회/순응/도주/저항/기절/체포/수감/재연행), 외형 무작위화  
- 3슬롯 인벤토리, 1인칭 손 뷰모델, 앉기, 점프, 이름표·스피커 아이콘, 3인칭 장착 아이템 동기화  
- 기능 정지(Die)와 본부 부활 장치, HUD(크로스헤어·채널링 게이지·아이템 윤곽선·상호작용 라벨)

**돌발 이벤트**

- 범인 탈옥, 전자기기 먹통(스캐너 불가 \+ 무전 왜곡 \+ CCTV 차단)

### 이번 빌드(빌드 4)에 추가된 것

**맵 / 레벨**

- 데모 씬 기반 임시 맵을 대체했다.  
- **상호작용 문** — 양쪽으로 열리는 대문  
- 수직 벽면에 착지하던 접지 판정 수정

**감옥 전면 개편**

- **판정 장소를 본부 인계존 → 감옥 문 앞으로 이관** — 인계존·인계 단말이 사라졌다. **문 옆 판정 버튼에 E**를 누르면 판정이 난다  
- **감옥을 컨테이너 박스의 별도 공간으로 교체** — 판정 버튼을 누르면 범인은 컨테이너 안으로 순간이동함.  
- **수감자 반출** — 앉은 수감자를 E로 일으키면 밧줄 없이 따라온다. 멀어져 멈추면 E로 재개, E로 다시 정지  
- **감옥 간판**(지금 몇 명 수감 중인지) · **감옥 CCTV 채널** · **본부 유치장 경보등**(자물쇠 해제 시도·탈옥을 색과 점멸로)  
- 수감자는 감옥 방 안을 배회한다

**돌발 이벤트**

- **추격 폭탄 — 시한폭탄 교체** — 도시에 미리 놓인 상자에서 폭탄이 나와, 사람이 다가오면 카운트다운을 시작하고 **가장 가까운 현장 플레이어를 쫓아온다**. **진압봉으로 때리면 그 자리에서 즉발**한다.  
- **플레이어 납치** — 혼자 다니는 현장 플레이어를 납치범 2명이 붙잡아 외곽까지 끌고 감. 붙잡힌 플레이어는 어떤 동작도 불가능하여 동료가 달려가 납치범을 때려 떼어내는 구조다.  
- **이벤트 NPC도 신원을 배정받는다** — 난동꾼·침입자가 스캔되지 않고 인명부에도 없던 문제 해소

**본부 (관제)**

- **유치장 사이렌 버튼**(상점 설치형) — 본부에서 눌러 **진행 중인 탈옥을 원격 제지**한다. 연타 방지 쿨다운  
- **수금 진행도 게시판** — 화면에 붙어 있던 팀 자금 HUD를 걷어내고 본부 게시판으로 옮겼다  
- **비밀 청탁** — 전화를 **받은 사람에게만** 걸리는 개인 의뢰. 수행하면 개인 자금을 획득한다.  
- CCTV 화면에 플레이어 이름표가 보이지 않도록 함

**게임 루프 / 경제**

- **개인 자금** — 수배범을 직접 끌고 와 넣은 사람에게 정산 시 현상금의 일부가 개인 몫으로 들어간다. 본인의 **잔액은 본인만 본다**(후속 기능의 정보 비대칭 기반)  
- 정산 화면에 개인 몫 표시

**플레이어 / 전투**

- **HP 0이면 곧바로 기능 정지(Die)** — 다운 상태에서 60초 안에 구조받던 창을 폐지했다. 복구 경로는 **밧줄로 운반해 본부 부활 장치에 안치**하는 것뿐이다  
- **진압봉 아군 오사** — 동료를 때리면 HP가 깎인다 (빌드 3 임시 처리 해소)  
- **밧줄 조작 정리** — 좌클릭은 줄을 거는 쪽(묶기·합류·재개), **E는 푸는 쪽**으로 갈랐다. 풀기는 홀드 없이 즉시, 묶인 대상은 누운 자세를 유지하다 풀릴 때 일어나는 모션을 거친다  
- **마이크 음소거 토글(M) \+ 음성 연결 상태 표시** (빌드 3 임시 처리 해소)  
- **1인칭 손가락 굽힘 수정** — 아이템을 들면 관절이 꺾이던 문제, 검지를 방아쇠에 맞춤, 밧줄 파지 회전 (빌드 3 임시 처리 해소)  
- **래그돌 기능 구현** — 플레이어가 쓰러지면 관절에 힘이 빠진 상태 구현

**연출 / 사운드**

- **사운드 시스템 도입** — BGM(씬 전환 페이드) \+ 효과음. 발소리, 스캔 판독음, 검거 판정음, 채널링 판독음, 경범죄 성공음. "세상에서 난 소리는 3D / 본인 확인음은 2D"로 분리  
- **피격 연출** — 진압봉 타격 먼지·히트마커·타격음, 테이저 아크·피격음, 피격 비네트, 화면 흔들림. 연출 재생 경로를 한 곳(FxManager)으로 모았다  
- **NPC 체력 바** — 조준한 대상만 머리 위 월드 UI로. 쓰러졌거나 끌려가는 대상은 제외

**UI 정식화 (임시 IMGUI 제거)**

- **공용 토스트 UI** 도입 — 추격 경고·거절 안내 등을 캔버스로  
- **신호 해석기 입력창**을 TMP 패널로 (한글 IME 표시 깨짐·씬 전환 시 입력/커서 복원 포함)

**로컬라이제이션 (String Table)**

- **한국어(ko-KR) · 영어(en) 2개 로케일** — 설정 창 언어 드롭다운으로 즉시 전환

**시스템**

- **전원 준비 완료 게이트** — 각 피어가 "내 화면이 준비됐다"를 보고하고 서버가 확인한 뒤 라운드를 시작한다. 대기 중에는 "대기 중 (2/4)" 표시 (빌드 3 임시 처리 해소)

## 임시 처리

- **번역 미적용 구간**: 서버가 네트워크로 실어 보내는 안내 문구(토스트 계열)는 아직 서버 언어 그대로 나온다 — 별도 이슈로 분리해 둔 상태  
- **로딩 화면**: **페이드 인·진행 바는 없다** (참가자 전원 로드 대기는 준비 게이트로 해소됨)  
- **개인 자금은 쓸 곳이 없다**: 비밀 청탁 보상과 정산 표시까지만 — 소비처(약탈 등)는 다음 빌드 대상  
- **납치 이후**: 납치당한 플레이어의 시체가 맵 밖으로 벗어날 때, 카메라가 1인칭으로 계속 남아있다. 관전 기능 추가 예정  
- **세이브/로드 미구현**: 저장 범위(세션 단위 / 계정 단위)는 논의 중  
- **래그돌 적용 이후 부활**: 죽은 플레이어를 직접 부활 구역 내로 올려놔야 함
