# 빌드 3 빌드 노트

---

## 시작 방법 (세션 접속)

1. 게임 실행 → 타이틀 화면에서 자동/수동 로그인 (UGS 익명 인증). 계정을 연동해 두면 **다른 기기에서도 같은 닉네임으로 접속**된다  
2. **호스트**: `세션 만들기 (Create)` → 생성된 Join 코드를 팀원에게 공유  
3. **참가자**: Join 코드 입력 → `코드로 참가 (Join)`  
4. **로비** — 접속자 목록에서 서로의 닉네임·방장·발화 상태를 확인하고, 호스트가 `시작` 버튼을 누르면 상점으로 이동  
5. **상점** — 팀 정산금으로 아이템을 구매한다. 구매품은 팀 소유로 등록되어 **다음 라운드부터 본부 택배 지점으로 배달**된다. 호스트가 `출동 게이트`에 E를 누르면 게임 맵으로 출발  
6. **게임 맵** — 로딩 화면이 걷히고 라운드가 시작된다 (NPC 스폰 → 진범 배정 → 수배 리스트 게시). 기본 지급품(스캐너·밧줄·진압봉)은 게임 씬 진입 시 지급되고, 구매품은 본부 택배 지점에 놓인다  
7. **라운드 목표는 금액이다** — 제한시간 안에 목표 금액만큼 벌어들인다. 진행도는 *지금 유치장에 잡아둔 대상들의 현상금 합*이라 탈옥하면 진행도도 줄어든다  
8. 목표를 채우면 **본부의 라운드 종료 버튼이 활성화**된다. 팀이 원할 때 눌러 끝내거나, 더 벌고 싶으면 제한시간까지 계속 수사한다 (안 눌러도 목표를 넘겨 있으면 성공)  
9. 라운드가 끝나면 정산 화면을 거쳐 다시 상점으로 복귀 — 세션이 유지된 채 다음 라운드로 이어짐

## 조작 방법

| 입력 | 동작 |
| :---- | :---- |
| WASD / 방향키 | 이동 |
| 마우스 | 시점 회전 (설정 창에서 감도 조절) |
| Left Shift | 달리기 |

| E | 상호작용 — 아이템 줍기, **끌던 대상 놓기 / 재연행(끌기 재개)**, **본부 인계 판정**, 다운된 동료 구조(홀드), **기능 정지(Die) 동료를 부활 장치에 안치**, CCTV 버튼·전원, 제보 전화 받기, **라운드 종료 버튼**, 인명부·문양 대조판, 신호 해석기, 스캐너 충전기, 유치장 문, 폭탄 매뉴얼·전선, **상점 구매** |

| 1 · 2 · 3 | 아이템 슬롯 직접 선택 |
| G | 장착 아이템 버리기 |
| Tab | 인벤토리 |
| V (홀드) | 무전 (Push-to-Talk) |
| ESC | 일시정지 패널 — 설정 창, 나가기 확인창, 메인 메뉴 복귀 |

## 구현된 기능

> 지난 빌드(주간 빌드 1·2)에서 이미 있던 기능과, 이번 빌드(주간 빌드 3)에 추가된 기능을 나눠 표기.

### 지난 빌드(빌드 1·2)에서 구현된 것

**네트워크 / 세션**

- UGS 익명 로그인, Relay 기반 세션 생성·코드 참가 (최대 6인)  
- Vivox 음성 채팅 — V 홀드 무전 \+ 근접 음성  
- 타이틀 → 로비 → 상점 ↔ 게임 맵 루프, ESC 일시정지 패널

**라운드 / 정산**

- 라운드 종료 조건, 종료 사유 표시, 라운드 정산 화면, 팀 공용 자금, 유치장 점유 기반 정산

**현장 (수사 · 검거)**

- 스캐너(배터리 소모 \+ 본부 충전), 스캔 정보 NPC 월드 카드 \+ 미스캔 `??` 마스킹  
- 연행 / 본부 인계 / 검거·오검거 판정 배너, 위조범 즉결 처리, 오검거 페널티(추격·포획·호송)  
- 테이저건, 밧줄 끌기, 유치장 수감, 다운 · 구조

**본부 (관제)**

- CCTV, 수배 리스트(몽타주), 시민 인명부 \+ 이름 위조, 외형 대조 6축, 신호 해석기

**돌발 이벤트**

- 범인 탈옥

**NPC / 플레이어**

- 시민 FSM(배회 / 순응 / 도주 / 저항 / 기절 / 체포 / 수감 / 재연행), 외형 무작위화  
- 3슬롯 인벤토리, 1인칭 손 뷰모델, 앉기, 이름표 \+ 스피커 아이콘, 3인칭 장착 아이템 동기화  
- HUD: 크로스헤어, 채널링 게이지, 바닥 아이템 윤곽선, 상호작용 라벨, 검거 할당량

### 이번 빌드(빌드 3)에 추가된 것

**검거 흐름 전면 개편**

- **기본 검거 수단을 수갑에서 밧줄로 이관** — 수갑 아이템 폐기. 밧줄로 검거 대상 질질 끌고다님.  
- **진압봉 타격** — 근접 스윙 타격으로 NPC 체력을 깎는다.  
- **NPC 체력 시스템** — 기존 제압 게이지를 체력으로 통합, 체력 0 시 기절  
- **E 제압 제거** — 도주형 3초 홀드 제압 삭제  
- **밧줄은 무력화된 대상만 묶는다** — 깨어 있는 NPC에겐 무동작. 쓰러진 대상은 홀드 없이 좌클릭 한 번에 즉시 묶임  
- **반응 트리거 변경 — 검거 시도 → 스캔·피격** — "잡으려 하면 도망간다"가 "**의심받으면(스캔) 도망간다**"로. 순응형은 스캔에 무반응이지만 피격당하면 도주·저항 중 랜덤  
- **밧줄 1개당 NPC 1명 — 여러 명 동시 끌기** — 플레이어가 여러 명의 NPC를 끌고다닐 수 있음.  
- **NPC 무게 시스템** — 끄는 플레이어 이동속도에 페널티. **여러 명이 함께 끌면 무게 ÷ 참가자 수로 완화**  
- **본부 인계 판정을 콜라이더 자동 → E 수동으로 전환** — 판정 버튼에 E를 눌러야 판정이 난다  
- **테이저 쿨다운 5초를 채널링 게이지로 표시** — 게이지가 차는 순간이 재발사 가능 시점  
- **테이저 아군 오사** — 동료를 맞추면 5초 기절 (구조 대상이 되지 않는 별도 무력화 경로)

**게임 루프 / 라운드**

- **라운드 클리어 조건을 검거 인원 수 → 목표 금액으로 전환** \+ **현상금 라운드마다 랜덤화**. 진행도는 유치장 점유 현상금 합  
- **본부 라운드 종료 버튼** — 목표 달성 시 활성화, 팀이 원할 때 종료. 안 눌러도 제한시간에 목표를 넘겨 있으면 성공  
- **상점 구현** — 진열대 조준 시 정보 카드, E로 구매. 구매품은 다음 라운드 본부 택배 지점에 배달  
- **아이템 지급 시점을 게임 씬 진입으로 이동** — 상점은 빈손 대기, 매 라운드 회수 → 재지급  
- **씬 전환 로딩 화면** \+ **라운드 시작 준비 단계** — NPC 스폰까지 끝난 뒤 화면이 보임  
- **설정 창 UI** — 마우스 감도 · 마스터 음량 · 음성 음량 (즉시 적용 \+ 기본값 복원)  
- **인게임·상점 나가기 확인창**, 타이틀 종료 확인창

**로비 / 계정**

- **로비 접속자 목록** — 로스터 동기화(닉네임 · 방장 · 음성 상태) \+ 호스트 시작·나가기 버튼. 로비에는 플레이어 오브젝트가 없으므로 전용 로스터로 구현  
- **사용자별 닉네임 영속 저장** — UGS PlayerName 정본 \+ PlayerPrefs 로컬 캐시 하이브리드  
- **계정 연동** — 닉네임의 기기 간 유지  
- **계정 편도 상태 탈출 경로** — 연동 확인창 \+ 새 익명 계정 전환  
- **세션 나가기와 로그아웃 분리** — 메인 메뉴로 돌아가도 인증이 유지된다

**플레이어**

- **기능 정지(Die) 상태** — 다운 상태로 60초 안에 구조받지 못하면 Die로 악화. 게임오버 판정에 포함  
- **Die 동료 운반 \+ 본부 부활** — NPC와 같은 밧줄로 묶어 끌고, 본부 부활 장치에 E로 안치하면 30초 후 부활. 진행 중 누가 다시 끌어가면 타이머 취소  
- **점프** (Space) — 접지 상태에서만, 공중 재점프 없음, 다운·라운드 종료 중 차단

**본부 (관제)**

- **CCTV 위치·선택 식별 UI** — 화면 전환/전원 버튼 분리, **미니맵 CCTV 마커**, 채널 라벨  
- **제보 전화** — 간헐적으로 울리고 받으면 예비 용의자 1명이 수배 리스트에 공개됨. 자리를 비워 놓친 전화도 횟수를 소모한다  
- **세력 문양(Faction Symbol) 대조 데이터** — 프로필 ↔ 본부 대조판 매칭

**돌발 이벤트**

- **전자기기 먹통** — 스캐너 사용 불가 \+ 무전 음성 왜곡(기계음) \+ **CCTV 송출·전원 차단**.

## 임시 처리

- **UI 전반**: 상당수 UI가 정식 교체됐지만(설정·로비·정산·CCTV·상점) 아래는 여전히 임시 IMGUI다 — **신호 해석기 입력창**, 팀 자금 표시, 구조 프롬프트, 폭탄 매뉴얼·위치 표시, 오검거 페널티 표시, 씬 표시 HUD, 세션/로그인 상태창  
- **맵**: 유료 에셋 Demo Scene 기반을 정리해 사용 중, 추후 교체 예정  
- **로딩 화면 1차 구현**: 덮기 \+ 페이드아웃까지만. **페이드 인 · 진행 바 · 참가자 전원 로드 대기는 아직 없다**  
- **진압봉 아군 오사 미구현**: 진압봉으로 동료를 때려도 빗나감 처리 — 테이저만 아군 오사가 있다  
- **이벤트 스폰 NPC 스캔·명부 미지원**: 이벤트로 스폰된 NPC는 프로필이 없음  
- **1인칭 손**: 아이템을 들었을 때 손가락 관절이 이상한 방향으로 꺾인다  
- **음성 편의 기능 없음**: 마이크 음소거 토글 · 음성 연결 상태 표시 미구현
