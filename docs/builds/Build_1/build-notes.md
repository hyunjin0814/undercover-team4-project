# 빌드 1 빌드 노트

---

## 시작 방법 (세션 접속)

1. 게임 실행 → GUI에서 자동/수동 로그인 (UGS 익명 인증)
2. **호스트**: `세션 만들기 (Create)` → 생성된 Join 코드를 팀원에게 공유
3. **참가자**: Join 코드 입력 → `코드로 참가 (Join)`
4. 호스트 접속 시 라운드가 자동 시작됨 (NPC 스폰 → 진범 배정 → 수배 리스트 게시)

---

## 조작 방법

| 입력 | 동작 |
|------|------|
| WASD / 방향키 | 이동 |
| 마우스 | 시점 회전 |
| Left Shift | 달리기 |
| E | 상호작용 — 아이템 줍기, NPC 체포·제압·재연행, 연행 놓기, 다운된 동료 구조(홀드), CCTV 화면 전환 |
| 좌클릭 (홀드) | 장착 아이템 사용 — 수갑: 체포 채널링 / 스캐너: 스캔(3초 채널링) |
| 마우스 휠 | 아이템 슬롯 전환 |
| 1 · 2 · 3 | 아이템 슬롯 직접 선택 |
| G | 장착 아이템 버리기 |
| Tab | 인벤토리 |
| V (홀드) | 무전 (Push-to-Talk) |
| ESC | 마우스 커서 잠금/해제 (임시 — GUI 버튼 조작용) |

## 구현된 기능

### 네트워크 / 세션
- UGS 익명 로그인, Relay 기반 세션 생성·코드 참가 (최대 6인)
- Vivox 음성 채팅 — V 홀드 무전 + 근접 음성
- 세션 접속 시 플레이어 스폰

### 라운드
- 종료 조건: 진범 검거 할당량 달성(성공) / 제한시간 초과(실패) / 플레이어 전원 다운(실패)
- **라운드 종료 시 모든 플레이어 화면에 종료 사유 표시** (이번 빌드 신규, #210)
- 종료 후 자동으로 세션 정리 → 첫 화면(메인 메뉴)으로 복귀

### 현장 (수사 · 검거)
- **스캐너**: 좌클릭 홀드 3초 채널링으로 시민 정보 확인 — 배터리 소모식, 본부 충전기로 충전
- **수갑**: 좌클릭 홀드 채널링으로 체포 — NPC 반응(순응/도주/저항)에 따라 전개가 갈림
  - 도주 NPC는 추격해서 E로 체포, 저항 NPC는 E 제압 타격으로 게이지를 깎음 (여럿이 함께하면 더 빠름)
- **연행**: 체포한 NPC를 본부 인계 구역까지 데려가면 검거 판정 (진범 / 오검거)
- **다운·구조**: HP가 0이 되면 행동불능 — 동료가 조준 후 E 홀드 채널링으로 소생

### 본부 (관제)
- CCTV — 모니터에 상호작용(E)하면 화면 전환
- 수배 리스트 — 진범 몽타주 표시, 검거 시 항목 제거 (전 클라이언트 동기화)

### NPC
- 시민 FSM: 배회 / 순응 / 도주 / 저항 + 라운드마다 진범 무작위 배정, 외형 무작위화

### 플레이어
- 3슬롯 인벤토리 (줍기 / 버리기 / 슬롯 전환), 손 장착 뷰
- HUD: 크로스헤어, 채널링 게이지, HP

## 임시 처리

- **UI 전반**: 세션/로그인/무전 상태창, 라운드 종료 텍스트, HP·게이지 등 모든 UI는 테스트 편의를 위한 임시 배치 — 정식 UI 작업에서 교체 예정
- **맵**: 유료 에셋에서 기본 제공된 Demo Scene을 재사용 중 — 추후 자체 맵으로 변경 예정
- **게임 종료**: 제한시간 종료 혹은 범인 체포 성공 시에 세션을 강제 종료 (빌드 2에 수정 예정)
- **ESC 커서 토글**: GUI 버튼 조작용 임시 처리 — 정식 메뉴 UI가 들어오면 제거 예정
- **디버그 라벨**: 호스트 화면에는 진범 머리 위에 "범인" 라벨이 표시됨 (정답 노출)
- **저항형 NPC**: 임의로 넣은 애니메이션으로 공격 동작과 타격 판정 동기화 안됨 - 빌드 2에 수정 예정
- **범인 몽타주**: 범인을 특정할 수 있는 외형 필터링 정보를 임의로 정의함 - 현재는 임의로 범인 모델에 외형 정보 추가 (빌드 2에 리팩토링 예정)
- **스캔 배터리**: 배터리 부족 UI로 표시되지 않음. 스캔이 안되면 본부의 충전기로 충전 가능 (충전 UI도 표시 안됨)
- **범인 검거**: 범인 검거하고 인계를 안하면 가만히 있음 (빌드 2에 NPC 리팩토링에 추가할 예정)
- **범인 체포 판정**: 본부 인계존에 검거한 범인을 데려오면 판정 결과 피드백이 안나옴 (실제로는 판정 중)
- **플레이어 시각 피드백**: 플레이어와 NPC가 구분이 안됨 (빌드 2에 추가 예정)
- **음성 채팅 시각 피드백**: 누가 말하고 있는지 시각적으로 알 수가 없음 (플레이어 시각 피드백 해결하면서 같이 수정 예정)
