# 4팀 빌드 1 다음 빌드 계획

## 다음 빌드 목표
- **메인 메뉴 → 로비(상점) → 게임 맵 → 라운드 정산 → 로비 복귀**로 이어지는 게임 루프 완성 + 콘텐츠(아이템/이벤트/대조 데이터) 확장 및 기술 부채 정리

### 게임 플로우 / 씬 구성

- 메인 메뉴 → 로비 및 상점 → 실제 게임 맵 씬 전환 흐름 구축
- 로비 구현 — 게임 시작 전 대기 공간 및 플레이 맵 이동
- 라운드 종료 후 정산금을 가지고 로비 복귀 — 라운드 순환 및 회차 게시판
- 상점 구현 — 로비에서 팀 정산금으로 아이템 구매
- 게임 맵 구성

### 플레이어

- 마우스 회전 부드럽게 개선
- 플레이어 타격 기능
- 플레이어 이름표 — 멀티플레이에서 플레이어 구분 (UGS PlayerName/닉네임 기반)
- 플레이어 점프 기능 및 점프 애니메이션
- 플레이어 감정표현 — 애니메이션 적용된 감정표현 및 이모지
- 플레이어 손에 장착 아이템 3인칭 표시 — 멀티플레이 전 피어 동기화

### NPC

- NPC 공격 애니메이션 리팩토링
- 도주 NPC 다중 위협 회피 — 단일 위협 기준 도주 방향을 다중 플레이어 기반으로 교체
- NPC 일정 기간 인계 안할 시에 수갑 해제 후 도주

### 본부(HQ) / 데이터

- 몽타주 데이터 세분화 리팩토링
- 본부에서 대조할 데이터 추가 — Faction(문양), 대조 심볼 이미지는 AI로 생성
- 시민 인명부 본부 배치 — 스캔 정보와 대조해 위조 여부 구두 판단
- 제보 전화 — 본부 수신 시 수배 리스트 갱신 (다수 용의자)
- 유치장 구현 - 판정 구역과 범인 실제 관리 구역을 따로 분리
    - 인계존 판정 후, 범인은 감옥(관리 구역)으로 이동해 관리
    - 시민으로 판정되면 수갑 해제 + 오검거 카운트 증가

### 아이템

- NPC에게 수갑 사용 시 인벤토리에서 사라지고 인계존에서 판정 후에 수갑 아이템 돌려받기 (판정 결과 시 수갑이 바닥에 떨어지는 형태 — 방식 미확정)
- 추가 아이템 3종 — 테이저건 / 신호 해석기 / 호루라기
- 아이템 에셋 찾기 
- 팀 공용 자금 — 검거 보상 합산

### UI

- 스캔 정보를 NPC에게 이관 (스캔 정보는 NPC에 종속)
    - 미스캔 NPC: 마우스 레이캐스트가 닿으면 정보가 `??`로 마스킹되어 표시
    - 스캔 완료 NPC: 실제 정보가 제대로 출력
- 플레이어와 NPC 구분 및 음성 채팅 여부 UI — 머리 위 이름표 UI에 스피커 아이콘 결합(발화 중 시각 피드백)
- 메인 메뉴 UI
- 라운드 정산 화면 UI
- 설정 창 UI
- 본부에서만 확인 가능한 미니맵

### 게임 진행 / 규칙

- 오검거 페널티 — 개인 카운트(플레이어에게 미표기) + 광장 매달기(행동불능)
    - 허용치 초과 시, 본부 옆에 상주하던 오검거 NPC들이 초과한 플레이어를 끌고가 매달기
    - 마지막에 허용치를 넘긴 플레이어가 패널티 대상
- 이벤트 추가 (라운드 중 발생 — 종류 확정)
    - 날씨: 번개(피격 시 체력 감소 or 이속 버프) / 안개(시야 제한) / 눈(빙판 미끄러짐)
    - 범인 탈출: 본부 무인 시 확률로 범인이 본부 진입, 유치장 자물쇠 해제
    - 폭탄: 시한폭탄 필드 설치 → 제거

### 리팩토링 / 기술 부채

- 통합 세션 정리 리팩토링 (세션 → NGO → Vivox → 로그아웃)

### 확정 (이번 회의 결정)

- Firebase 미도입 — UGS 단독 사용 (인증·Relay·Lobby·Vivox 스택 정합성; Firebase는 실시간 멀티플레이 transport 없음)
- 플레이어 이름표 — UGS PlayerName(닉네임) 사용. 익명 로그인 후 기본 닉 자동 부여 + 플레이어 수정 가능 (AuthBootstrap)
    - 표시 트리거(항상 표시 vs 근접 시)는 UI 구현 단계에서 결정

### 통합 검증

- 메인 메뉴 → 로비 → 게임 맵 → 정산 → 로비 복귀 풀 사이클 멀티플레이 테스트
