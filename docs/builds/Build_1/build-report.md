## 1. 이번 빌드에서 기대한 플레이 경험

빌드 노트의 구현 기능 기준으로, 이번 빌드에서 플레이어가 경험할 것으로 기대한 흐름은 다음과 같다.

### 세션 접속 흐름
- 게임 실행 후 GUI에서 UGS 익명 로그인으로 자동/수동 접속.
- 호스트가 `세션 만들기(Create)`로 방을 열고, 생성된 Join 코드를 팀원에게 공유.
- 참가자는 코드를 입력해 `코드로 참가(Join)`로 합류 (최대 6인).
- 호스트 접속 시 라운드가 자동 시작 — NPC 스폰 → 진범 배정 → 수배 리스트 게시까지 별도 조작 없이 이어지는 경험.

### 협동 추리 루프 (본부 vs 현장)
- **비대칭 협동:** 한쪽은 본부(관제), 한쪽은 현장(수사)으로 나뉘어 무전으로 협력하는 경험을 기대.
- **현장:** 스캐너로 시민 정보 확인(3초 채널링, 배터리 소모) → 용의자를 수갑으로 체포 → NPC 반응(순응/도주/저항)에 따라 추격·제압으로 전개가 갈림 → 본부 인계 구역으로 연행해 검거 판정(진범/오검거). 동료가 다운되면 구조로 복귀시키는 상호 의존적 플레이.
- **본부:** CCTV 모니터(E)로 화면을 전환하며 현장을 관측하고, 수배 리스트의 진범 몽타주를 현장에 무전으로 안내. 검거 시 항목이 전 클라이언트에 동기화되어 제거됨.

### 음성·소통
- Vivox 근접 음성 + V 홀드 무전(Push-to-Talk)으로, 텍스트 없이 실시간 협업하는 경험.

### 라운드 종료 경험 (이번 빌드 신규, #210)
- 진범 검거 할당량 달성(성공) / 제한시간 초과(실패) / 전원 다운(실패) 중 하나로 라운드 종료.
- **종료 시 모든 플레이어 화면에 종료 사유가 표시**되어, 왜 끝났는지 공유되는 마무리 경험.
- 종료 후 자동 세션 정리 → 메인 메뉴 복귀로 다음 판을 다시 시작할 수 있음.

### 플레이어 개인 경험
- 3슬롯 인벤토리(줍기/버리기/휠·숫자 슬롯 전환), 손 장착 뷰.
- HUD로 크로스헤어·채널링 게이지·HP 확인.

> 참고: UI 전반, 맵(데모 씬), ESC 커서 토글, 호스트 화면 "범인" 디버그 라벨, 저항형 NPC 애니메이션, 범인 몽타주 필터 정의는 **임시 처리**로, 정식 작업/빌드 2에서 교체·리팩토링 예정.

## 2. 플레이 테스트 결과 (발견 이슈)

플레이 테스트에서 확인된, 기대 경험을 해치는 문제 5건.

### 이슈 A — 마우스 시점 회전이 부드럽지 못함
- **증상:** 마우스로 시점을 회전할 때 움직임이 매끄럽지 않고 끊기거나 뻑뻑한 느낌.
- **영향:** 조작감의 기본이 되는 부분이라 현장 수사·추격 플레이 몰입도를 크게 떨어뜨림.
- **추정 원인 (검증 필요):** 회전 처리가 프레임 타이밍/입력 스무딩과 맞지 않을 가능성. 회전 로직이 `Update` vs `FixedUpdate` 어디서 도는지, delta time 적용 여부, 감도/스무딩 값 확인 필요.
- **우선순위:** 높음 (핵심 조작감).

### 이슈 B — 플레이어 간 구분 불가 (머리 위 식별 표시 없음)
- **증상:** 여러 플레이어가 화면에 있을 때 서로 누가 누군지 구분되지 않음.
- **요청 사항:** 플레이어 머리 위에 식별 표시 필요.
  - 익명 로그인이면 **PlayerId** 표시.
  - 닉네임이 있으면 **플레이어 닉네임** 표시.
- **영향:** 본부·현장 협동에서 "누가 어디 있는지" 지목이 어려워 무전 협업 경험이 약해짐.
- **우선순위:** 높음 (협동 게임 식별성).

### 이슈 C — 버린 아이템의 Collider가 남아 밟고 올라감
- **증상:** G로 아이템을 버렸을 때, 바닥에 놓인 아이템에도 Collider가 살아 있어 플레이어가 그 위를 밟고 올라감 (지형처럼 작동).
- **영향:** 이동·추격 중 예기치 않게 걸리거나 올라타 조작이 꼬임. 맵 이동 경험을 해침.
- **추정 원인 (검증 필요):** 아이템 프리팹의 물리 Collider가 줍기 트리거용 Collider와 분리되지 않았거나, 드롭 시 물리 Collider가 그대로 켜져 캐릭터 컨트롤러와 충돌함. 드롭 상태에서는 줍기용 트리거만 남기고 캐릭터가 밟지 않도록 레이어/Collider 설정 조정 필요.
- **우선순위:** 중간~높음 (이동 방해).

### 이슈 D — 빈 슬롯 전환 시 이전 아이템 이름 라벨이 사라지지 않음
- **증상:** 핫바에서 슬롯이 하이라이트되면 핫바 위에 아이템 이름이 일정 시간 표시됨. 아이템이 있는 다른 슬롯으로 전환하면 그 슬롯 아이템 이름으로 즉시 갱신되지만, **빈 슬롯으로 전환하면 이전 슬롯의 아이템 이름이 계속 떠 있음**.
- **기대 동작:** 빈 슬롯으로 전환하면 아무 이름도 표시하지 않아야 함 (라벨 즉시 제거).
- **영향:** 현재 들고 있는 것과 표시가 불일치해 슬롯 상태를 잘못 인지하게 됨.
- **추정 원인 (검증 필요):** 이름 라벨이 "일정 시간 표시" 타이머 기반인데, 아이템이 있는 슬롯 전환은 라벨 텍스트를 즉시 덮어써 갱신하지만, 빈 슬롯은 덮어쓸 새 텍스트가 없어 이전 라벨과 타이머가 그대로 남는 것으로 보임. 빈 슬롯 전환 시 라벨을 즉시 지우도록(텍스트 비우기 + 타이머 취소) 처리 필요.
- **우선순위:** 중간 (표시 정확성).

### 이슈 E — 체포된 NPC를 인계하지 않으면 제자리에 영원히 멈춰 있음
- **증상:** 수갑으로 NPC를 체포한 뒤 플레이어가 연행(인계)하지 않고 방치하면, 해당 NPC가 제자리에 영원히 멈춰 있음.
- **요청 사항:** 방치된 체포 상태에 해제 조건 추가 필요.
  - 체포 후 **일정 시간이 지나도 인계되지 않으면** 수갑 해제 후 도주.
  - 또는 **일정 거리 내에 플레이어가 없으면** 수갑 해제 후 도주.
- **영향:** 체포만 해 두고 방치해도 페널티가 없어 "체포 → 연행" 루프의 긴장감이 사라지고, 멈춘 NPC가 맵에 계속 쌓여 라운드 진행이 단조로워짐.
- **추정 원인 (검증 필요):** 체포(Captured) 상태가 스스로 다른 상태로 전이하지 않는 최종 상태로 구현되어 있음 — 이동을 멈춘 뒤 타이머/거리 등 어떤 조건으로도 빠져나가지 않아, 연행이 시작되지 않으면 영구히 유지됨. 체포 상태에 인계 대기 타이머 또는 주변 플레이어 거리 체크를 추가해 도주 상태로 전이시키는 처리 필요.
- **우선순위:** 중간 (게임 루프 긴장감).

## 3. 종합

이번 빌드는 세션 접속 → 라운드 자동 시작 → 본부·현장 협동 수사 → 검거/연행 → 라운드 종료 사유 표시 → 메인 메뉴 복귀까지 핵심 루프가 플레이 가능한 상태로 확인됨. 신규 #210(라운드 종료 사유 표시)도 동작.

다만 조작감(마우스 회전)·협동 식별성(머리 위 표시)·버린 아이템 Collider 3건이 플레이 경험을 직접적으로 해쳐, 빌드 2 우선 개선 대상으로 제안한다.

### 빌드 2 개선 제안 요약
| 이슈 | 내용 | 우선순위 |
|------|------|----------|
| A | 마우스 시점 회전 스무딩/감도 개선 | 높음 |
| B | 플레이어 머리 위 PlayerId/닉네임 표시 | 높음 |
| C | 버린 아이템 Collider가 캐릭터를 막지 않도록 수정 | 중~높음 |
| D | 빈 슬롯 전환 시 아이템 이름 라벨 즉시 제거 | 중간 |
| E | 방치된 체포 NPC에 해제 조건(시간/거리) 추가 — 수갑 해제 후 도주 | 중간 |
