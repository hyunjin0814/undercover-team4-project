## 1. 이번 빌드 요약

**메인 메뉴 → 로비 → 상점 -> 게임 맵 → 라운드 정산 → 상점 복귀**로 이어지는 게임 루프 완성이 됐다.
**몽타주 데이터** 리팩토링과 **인명부 시스템**으로 용의자 외형 필터링과 위조범을 판단할 수 있는 기본 로직이 완성되었다.
**범인 탈옥 이벤트**, **난동꾼 이벤트**, **폭탄 해체 이벤트**가 정상적으로 동작한다.

## 2. 플레이 테스트 결과 (발견 이슈)

플레이 테스트에서 확인된, 기대 경험을 해치는 문제 8건.

### 이슈 A — 벽 너머 아이템이 주워짐 (레이캐스트 벽 미인식)
- **증상:** 벽 너머에 있는 아이템이 벽에 가로막혀 있는데도 주워짐.
- **영향:** 물리적으로 닿을 수 없는 위치의 아이템을 획득해 공간 규칙이 깨짐
- **추정 원인 (검증 필요):** 줍기 판정 레이캐스트/오버랩 검사가 벽(장애물) 레이어를 차단 조건으로 포함하지 않음. 플레이어 → 아이템 사이에 장애물 레이캐스트 체크를 추가하거나, 줍기 레이캐스트의 LayerMask에 벽을 포함해 히트 시 차단하도록 수정 필요.
- **우선순위:** 높음

### 이슈 B — 아이템 드롭 시 위치 동기화 버그
- **증상:** 아이템을 버릴(드롭) 때 클라이언트 간 아이템 낙하/정착 위치가 일치하지 않음.
- **영향:** 본부·현장이 서로 다른 위치의 아이템을 보게 되어 아이템을 이용한 협업이 어긋남. 멀티플레이 신뢰도 직접 저하.
- **추정 원인 (검증 필요):** 드롭 위치를 각 클라이언트가 로컬로 계산하거나, 서버 권한으로 확정한 위치가 전 클라이언트에 동기화되기 전에 표시되는 것으로 보임. 드롭은 서버 권한으로 최종 위치를 확정하고 NetworkTransform/스폰으로 동기화하도록 경로 정리 필요. (소유권·서버 권한 확인)
- **우선순위:** 중간

### 이슈 C — 중복 판정 피드백 잔존 (정산 방식 개편 후 불필요 로직)
- **증상:** 정산 방식이 바뀌었는데, 이전 방식에서 필요했던 "중복 판정" 처리/피드백이 여전히 남아 있음.
- **기대 동작:** 새 정산 방식에서는 중복 판정을 처리하지 않으므로, 관련 로직과 피드백이 제거되어야 함.
- **영향:** 중복 판정은 피드백이 없기 때문에 판정 결과 인지에 혼란을 줌.
- **추정 원인 (검증 필요):** 정산 로직 개편 시 중복 판정 분기/피드백 코드가 함께 정리되지 않고 남음. 제거 필요.
- **우선순위:** 중간 (정산 정확성/정리).

### 이슈 D — 정산 누락: 돌발 이벤트 NPC가 정산에 반영되지 않음
- **증상:** 돌발 이벤트로 등장/생성된 NPC가 검거 정산에 계산되지 않음.
- **영향:** 정산 결과가 실제 검거와 불일치.
- **추정 원인 (검증 필요):** 정상 스폰 NPC와 돌발 이벤트 NPC가 서로 다른 경로로 생성되어, 정산 대상 집계에서 돌발 이벤트 NPC가 등록되지 않는 것으로 보임. 돌발 이벤트 NPC도 정산 대상에 포함되도록 등록 경로 통일 필요.
- **우선순위:** 높음 (정산/라운드 판정 정확성).

### 이슈 E — 유치장 상태 전환이 간헐적으로 안 됨
- **증상:** 검거 후 유치장으로 가는 상태 전환이 될 때도 있고 안 될 때도 있음.
- **영향:** 연행/수감 루프가 불안정해 시각적으로 유치장으로 잡혀간건지 불분명함.
- **추정 원인 (검증 필요):** 상태 전환 조건(도착 판정/트리거/네트워크 타이밍)이 경합(race)에 취약할 가능성. 인계 구역 도착 판정, 상태 전이 RPC 순서, 서버 권한 여부 확인 필요. (재현 조건 확보가 우선)
- **우선순위:** 높음 (핵심 루프 안정성).

### 이슈 F — [개선] 연행 중 범인 추종 범위 표시 + 정면 이동
- **요청 사항:** 범인을 끌고 올 때 따라오는 범위(추종 반경)를 시각적으로 표시하면 좋겠음. 검거 후 뒤에 범인이 따라오는지를 확인할 필요 없이 앞으로 가고 싶음.
- **영향(기대 효과):** 어디까지 벗어나면 범인을 놓치는지 직관적으로 파악 가능해 연행 경험이 명확해짐. 정면 이동으로 조작감 개선.
- **비고:** 버그가 아닌 UX 개선 요청. 추종 범위 시각화 방식(지면 원형 인디케이터 등)·연행 중 카메라/이동 처리 방안 별도 논의 필요.
- **우선순위:** 중간 (연행 UX).

### 이슈 G — [개선] CCTV 위치/현재 화면 식별
- **요청 사항:** 본부에서 CCTV가 맵의 어느 위치에 있는지, 그리고 지금 보고 있는 CCTV가 어떤 것인지 알 수 있게 하기. CCTV 목록/현재 선택을 보여주는 UI 제안.
- **영향(기대 효과):** 본부 관측 시 현재 시점의 공간 맥락을 파악해 현장에 정확히 무전 안내 가능. 관제 경험 강화.
- **비고:** 버그가 아닌 UX 개선 요청. 표시 형태(미니맵 상 CCTV 마커 + 피드 썸네일/현재 선택 하이라이트) 별도 디자인 필요.
- **우선순위:** 중간 (본부 관제 UX).

### 이슈 H — 테이저건 피격 후 상호작용/아웃라인 불량
- **증상:** 테이저건에 맞고 누워 있는(다운) 대상에 대한 상호작용이 잘 안 됨. 대상 Outline(하이라이트)도 잘 표시되지 않음.
- **영향:** 제압 후 후속 상호작용(체포/구조 등) 연결이 불안정하고, 상호작용 가능 대상 식별이 어려움.
- **추정 원인 (검증 필요):** 다운(피격) 상태에서 상호작용 판정 콜라이더/자세 변경으로 레이캐스트 히트가 빗나가거나, 상호작용 대상 등록·Outline 갱신이 상태 전환과 함께 처리되지 않는 것으로 보임. 다운 상태의 상호작용 타깃/콜라이더와 Outline 표시 조건 점검 필요.
- **우선순위:** 중간 (제압→후속 상호작용 연결).
