# 빌드 2 빌드 노트

---

## 시작 방법 (세션 접속)

1. 게임 실행 → 타이틀 화면에서 자동/수동 로그인 (UGS 익명 인증)  
2. **호스트**: `세션 만들기 (Create)` → 생성된 Join 코드를 팀원에게 공유  
3. **참가자**: Join 코드 입력 → `코드로 참가 (Join)`  
4. 로비 → 상점 → 게임 맵 순으로 진행되며, 게임 맵 진입 시 라운드가 자동 시작됨 (NPC 스폰 → 진범 배정 → 수배 리스트 게시)  
5. 라운드가 끝나면 정산 화면을 거쳐 다시 상점으로 복귀 — 세션이 유지된 채 다음 라운드로 이어짐

---

## 조작 방법

| 입력 | 동작 |
| :---- | :---- |
| WASD / 방향키 | 이동 |
| 마우스 | 시점 회전 |
| Left Shift | 달리기 |
| Left Ctrl (홀드) | 앉기 |
| E | 상호작용 — 아이템 줍기, NPC 체포·제압·재연행, 연행/밧줄 놓기, 다운된 동료 구조(홀드), CCTV 화면 전환, 본부 오브젝트(충전기·모니터 등) 사용 |
| 좌클릭 (홀드) | 장착 아이템 사용 — 수갑: 체포 채널링 / 스캐너: 스캔(3초 채널링) / 테이저: 발사 / 밧줄: 쓰러진 NPC 결박 |
| 마우스 휠 | 아이템 슬롯 전환 |
| 1 · 2 · 3 | 아이템 슬롯 직접 선택 |
| G | 장착 아이템 버리기 |
| Tab | 인벤토리 |
| V (홀드) | 무전 (Push-to-Talk) |
| ESC | 일시정지 패널 — 인게임 어디서든 메인 메뉴 복귀 |

## 구현된 기능

> 지난 빌드(주간 빌드 1)에서 이미 있던 기능과, 이번 빌드(주간 빌드 2)에 추가된 기능을 나눠 표기.

### 지난 빌드(빌드 1)에서 구현된 것

**네트워크 / 세션**

- UGS 익명 로그인, Relay 기반 세션 생성·코드 참가 (최대 6인)  
- Vivox 음성 채팅 — V 홀드 무전 \+ 근접 음성  
- 세션 접속 시 플레이어 스폰

**라운드**

- 종료 조건: 진범 검거 할당량 달성(성공) / 제한시간 초과(실패) / 플레이어 전원 다운(실패)  
- 라운드 종료 시 종료 사유 표시

**현장 (수사 · 검거)**

- 스캐너 — 좌클릭 홀드 3초 채널링으로 시민 정보 확인, 배터리 소모식 \+ 본부 충전기 충전  
- 수갑 — 좌클릭 홀드 채널링 체포, NPC 반응(순응 / 도주 / 저항)에 따라 전개 분기  
- 연행 / 인계 — 체포한 NPC를 본부 인계 구역까지 데려가면 검거 판정 (진범 / 오검거)  
- 다운 · 구조 — HP 0이면 행동불능, 동료가 조준 후 E 홀드 채널링으로 소생

**본부 (관제)**

- CCTV — 모니터 상호작용(E)으로 화면 전환  
- 수배 리스트 — 진범 몽타주 표시, 검거 시 항목 제거 (전 클라이언트 동기화)

**NPC**

- 시민 FSM: 배회 / 순응 / 도주 / 저항, 라운드마다 진범 무작위 배정, 외형 무작위화

**플레이어**

- 3슬롯 인벤토리 (줍기 / 버리기 / 슬롯 전환), 손 장착 뷰  
- HUD: 크로스헤어, 채널링 게이지, HP, 조준 대상 아웃라인

### 이번 빌드(빌드 2)에 추가된 것

**게임 루프 / 씬 흐름**

- **타이틀 → 로비 → 상점 ↔ 게임 맵** 루프 구축  
- **라운드 종료 후 세션 강제 종료 제거** — 정산 화면을 거쳐 상점으로 복귀해 다음 라운드로 이어짐  
- **ESC 일시정지 패널** — 인게임 어디서든 메인 메뉴 복귀  
- 게임 종료 버튼 \+ 세션 코드 UI 재배치

**라운드 / 정산**

- **라운드 정산 화면** — 검거 성과 기반 보상 정산  
- 팀 공용 자금 — 검거 보상 합산  
- 정산 기준 개편 — 라운드 종료 시 **유치장 점유 기반**으로 보상 계산

**현장 (수사 · 검거)**

- 스캐너 **배터리 / 스캔 실패 사유 UI 표시**  
- 스캔 정보를 **NPC 월드 카드**로 이관, 미스캔 항목은 `??`로 마스킹  
- 검거 상호작용 개선 — 도주 NPC는 추격해 E 3초 채널링, 저항 NPC는 E 3번 눌러 제압  
- 수갑 소모·반환 처리 — 사용 시 인벤토리에서 제거, 인계존 판정 후 반환  
- 검거 종료 시 수갑을 연행자 인벤토리로 회수 (꽉 차면 바닥 드롭), 체포된 NPC에게 좌클릭 채널링으로 수갑 해제  
- **테이저건** — 도주·저항 NPC 기절, 유효 대상 조준 시 크로스헤어 색 변경  
- **유치장** — 판정 구역과 범인 관리 구역 분리, 인계 후 수감으로 이어짐  
- **검거 / 오검거 판정 결과 인게임 배너 UI**  
- 위조범 검거 판정 — 경범죄 즉결 처리 \+ 위조 보상  
- **오검거 페널티** — 팀 카운트 차감, 오검거 NPC는 특정 구역 대기, 임계점 초과 시 플레이어 추격·포획·호송 연출  
- NPC 인계 방치 시 수갑 해제 후 도주

**본부 (관제)**

- **시민 인명부(명부)** 본부 배치 \+ 이름 위조  
- **외형 대조 시스템** — 몽타주 데이터 세분화  
- **신호 해석기** — 본부 고정 단말, E로 입력창을 열어 타이핑한 메시지(최대 20자)를 팀 전원에게 전송

**돌발 이벤트**

- **폭탄 이벤트** — 시한폭탄 필드 설치 → 제거  
- **범인 탈출 / 탈옥** — 유치장 자물쇠 해제, 해제 중인 NPC는 체포로 대응 \+ 화면 경보 UI  
- 이벤트 NPC 판정 후 제압까지 잔류

**NPC**

- FSM 상태 확장: 기절 / 체포 / 수감 / 재연행  
- 공격 애니메이션 리팩토링 / 테이저 기상 모션 / 저항 스윙 정지  
- 체포(Captured) 상태 애니메이션 — 구속된 느낌 강화

**플레이어**

- **1인칭 손 뷰모델** — 빈손 상태 포함  
- 앉기(Left Ctrl)  
- **3인칭 머리 수직 시선 추종** — 원격 화면에서 상대 시선 방향 표시 (상하만)  
- **플레이어/NPC 구분 이름표 \+ 음성 채팅 스피커 아이콘**  
- 장착 아이템 3인칭 표시 — 다른 플레이어 손에 든 아이템 동기화  
- 마우스 회전 부드럽게 개선  
- HUD 추가: **바닥 아이템 상시 윤곽선**, **상호작용 오브젝트 식별 라벨, 화면 상단에 검거 할당량 표시**

## 임시 처리 / 알려진 제한

- **UI 전반**: 세션/로그인/무전 상태창, 정산·판정·경보 등 상당수 UI는 테스트 편의를 위한 임시 배치 — 정식 UI 작업에서 교체 예정  
- **맵**: 유료 에셋 Demo Scene 기반을 정리해 사용 중, 추후 교체 예정  
- **유치장**: 유치장 공간을 본부 내부 공간으로 임시 처리함 — 추후 공간 분리 예정  
- **상점 구매 미구현**: 상점은 씬/복귀 지점으로만 동작하며, 정산금으로 아이템을 구매하는 기능은 아직 없음 — 신호 해석기도 구매 없이 기본 설치 상태로 배치됨  
- **신호 해석기 UI**: 임시 IMGUI 입력창 — 정식 UI 작업에서 교체 예정  
- **플레이어 타격·점프 미구현**: 플레이어 직접 타격, 점프는 아직 없음  
- **설정 창 없음**: 해상도/음량 등 설정 UI 미구현  
- **NPC 애니메이션**: 도주형 제압 시에 나오는 구르기 애니메이션 임시 처리(걸려 넘어지는 연출로 임시 지정) \- 추후 교체 예정  
- **이벤트 스폰 NPC 스캔·명부 미지원**: 이벤트로 스폰된 NPC는 프로필이 없음 \- 추후 팀원들과 상의 후 수정 방향 결정 예정
