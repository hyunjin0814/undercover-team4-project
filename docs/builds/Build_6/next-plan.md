## 1\. 폴리싱 및 버그 수정

### 진행 차단성 버그

- 호스트가 죽은 뒤 클라가 이탈하면 **전멸 판정이 돌지 않아 라운드가 끝나지 않는다** — 수정 PR이 올라와 있고 머지만 남았다
- **죽은 클라가 세션에서 나가면 호스트의 입력이 통째로 꺼진다**(커서 풀림 + 조작 불가). 조사 결과 운반과 무관했고, 사망 시 소유권이 서버로 넘어간 뒤 되돌아오지 않는 것이 원인이다
- 감옥 안에 눕힌 동료를 밖으로 꺼내지 못한다 — 나가기 순간이동이 운반체를 안 옮긴다
- 감옥에서 반출한 시체가 굳어서 놨다 다시 잡아야 움직인다
- 감옥에서 여러 명이 묶은 NPC를 한 명이 데리고 나가면 다른 참가자의 밧줄이 끊어지지 않는다

### 네트워크 표현

- 차량이 클라에서 떨리는 것처럼 보인다
- 상점·게임 씬 진입 시 로봇이 기본색으로 먼저 뜬 뒤 색이 입혀진다

### 전투 판정

- 도주형 NPC에게 진압봉이 가끔 빗나간다 — 임팩트 0.3초 지연과 크로스헤어가 약속하는 시점이 어긋난다

### UI / 편의

- 정산 칭호를 오검거 외 다른 스탯으로 확장 — "최다 진범 체포" 등은 집계 자체가 없어 새로 세야 한다

## 4\. 아이템 확장

### 구역 스캔

- 소지형 일회용. 쓰면 반경 N m 안에 **진범이 있으면 사이렌, 없으면 조용히** 끝난다
- "어디에 있다"가 아니라 **"이 안에 있다/없다"만** 주는 것이 핵심. 정해야 할 것은 사이렌 전파 범위와 재구매 동선이다

### 체력 회복 아이템

- 지금 **살아 있는 상태에서 HP를 되돌리는 수단이 하나도 없다** (회복은 부활과 라운드 사이 리셋뿐)
- 부활 키트에 힐을 얹지 않고 별도 아이템으로 둔다. **수치·형태는 기획 확정이 먼저 필요하다**

### 개인 자금 전용 구매품

- 개인 자금으로만 사는 물건을 두고, **잔액을 보는 화면**도 같이 붙인다 — 쓸 곳이 생기면 소매치기·아군 약탈의 무게가 살아난다
