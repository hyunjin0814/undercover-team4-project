# 빌드 6 빌드 결과 보고서 (초안)

---

## 1\. 이번 빌드 요약

**현상금 / 검거 판정**

- **수배 조건 도입** — 진범마다 `생사 불문`(Dead Or Alive) / `생포 필수`(Alive Only)가 배정되고 본부 수배 리스트에 표시된다. 생사 불문 대상을 시체로 인계하면 **현상금 감액**, 생포 필수 대상을 사살하면 **보상 0 + 조건 불충족 배너**
- 라운드가 올라갈수록 **수배 조건 난이도 상향**
- **검거 판정을 개체 일치에서 수배 조건 부합으로 전환** — 수배 행은 이름·몽타주·현상금만 남김
- **라운드가 갈수록 몽타주 화질이 떨어진다** (128→64→32→16px), 몽타주는 특징 텍스트를 빼고 얼굴 + 이름만

**본부 / 맵**

- **본부 실내를 전면 개편하고 유치장을 본부 별동으로 합쳤다** — 본관에서 철창 너머로 수감자가 보인다. 시체도 같은 경로로 판정 버튼을 거친다
- **자물쇠 조작을 배전반 해킹으로 교체**, 탈옥·석방 NPC가 본부를 지나 나간다
- **'전자기기 먹통'을 '시스템 해킹'으로** — 12초 자동 복구 폐기, **본부 책상 복구 단말에서 네 자리 코드를 10초 안에 입력**해야 해제. 먹통 중에는 본부 미니맵도 가려진다
- **미니맵** — 빈 사각형 배경을 실제 맵 항공뷰로 교체, 납치범 빨간 아이콘 · 범위형 이벤트 반투명 원
- **맵 선택 콘솔**에 항공뷰 그림과 스폰 NPC 수 표시

**플레이어**

- **HP 0은 즉시 사망이 아니라 60초 유예(다운)** — 동료가 E로 손을 대고 있으면 키트 없이 일으키고, 유예 중 추가 피해는 즉시 완전 사망. 완전 사망은 **부활 키트로만** 복구
- **로봇 색 커스터마이징** — 로비에서 머리·상체·하체를 각각 칠하고 **계정에 저장**돼 다음 실행에도 유지
- **플레이어 HP를 기름통 게이지로** 교체 (피격·저체력 누유 연출)
- **1인칭 멀미 대응** — 시점 스무딩·감도 재조정 + 설정 창에 시점 부드러움·시야각·화면 흔들림·속도 비네트 노출
- 동료를 운반할 때도 **무게 페널티**를 진다 (NPC 견인과 같은 합)
- **키 변경** — 인벤토리 `Tab` → `I`, 약탈 `E` → `R`, `Tab`은 팀 상황판(홀드)

**HUD / UI**

- **조준한 대상에 눌러야 할 조작키를 띄운다** — `[E] 문 열기` 형태, 지금 못 쓰는 대상이면 막힌 사유까지
- **Tab 홀드 팀 상황판** — 동료의 얼굴·이름·체력·상태(생존/납치/기능 정지) + 이번 라운드 수배 몽타주
- 정산 패널을 **결과 / 팀 자금 / 내 몫 / 칭호 4줄**로 단순화, 최다 오검거는 칭호로 표시
- **겨냥 없이 E로 밧줄 풀기** — 끌던 대상을 돌아봐야 풀리던 조작 개선

**래그돌 — 시체가 모두에게 같게 보인다**

- 원격 피어가 각자 물리를 굴리고 골반만 복제하던 구조를 **권위 피어만 시뮬레이션하고 나머지는 전 뼈 자세를 받아 재생**하는 구조로 교체. 플레이어 래그돌도 같은 구조로 통일하고 사망 전용 모델을 걷어냈다
- 그 과정에서 **간헐적 슬로모션**(권위 피어 프레임레이트에 쓰러지는 속도가 묶여 있던 것)을 없앴고, 2 PC 빌드 실측으로 확인했다

**NPC**

- **방치된 NPC는 체력이 서서히 회복된다** — 마지막 피해로부터 20초 무피해면 초당 2HP씩 최대치까지
- 저항 NPC가 피격 직후 **첫 타격을 바로 휘두른다**, 등 뒤에서 맞으면 돌아선 뒤에 휘두른다
- 시민 이름 풀을 데이터 에셋으로 빼고 한/영 각 150~200개로 확장
- 맵에 주차된 장식 차량을 NavMesh 장애물로 바꿔 NPC가 통과하지 못하게 함

**돌발 이벤트 / 환경**

- **폭주 차량이 상시 교통이 됐다** — 도로에 차가 계속 지나가고, **닿으면 즉사이며 시민도 같은 피해**를 받는다. 환경이 죽인 시민은 오검거로 세지 않는다. 밧줄에 묶인 NPC도 환경 피해로 죽는다
- **날씨는 라운드마다 하나만 뽑아 라운드 내내 지속된다** — 돌발 이벤트 추첨에서 빼고 `맑음 + 3종` 4택으로, 라운드가 오를수록 맑음 확률 하락. 실내 강수 표현(창·문 너머로 보이고 지붕 아래에서는 안 내림)과 실내 빙판 제외도 함께
- **납치 이벤트 개편** — 납치범이 걸어서 뒤로 돌아 **후방에서만 포획**하고, 결말을 린치·처형·도보 반출에서 **맨홀 하강**으로 교체. 뚜껑이 열리는 동안이 마지막 구조 창이고, 내려가기 시작하면 라운드 아웃이다
- 추격 폭탄 **폭발이 NPC에도 플레이어와 같은 곡선으로 피해**를 준다

**네트워크 / 세션**

- **버전이 다른 클라이언트를 연결 승인 단계에서 거절한다** — 참가 후 스스로 물러나며 로비가 잠깐 보였다 사라지던 것을 없앴고, 검사 코드가 없는 구버전 클라도 막는다. 빌드에 **커밋 sha를 자동으로 굽는다**(버전 섞임 진단용)
- **세션이 끊기면 사유를 토스트로 알린다** — 호스트 이탈 / 연결 끊김 / 세션 삭제 구분
- **호스트와 클라가 같이 로딩 화면으로 넘어간다** — 서버가 덮기 직전에 전환을 예고. 호스트가 1초쯤 먼저 뜨던 것이 사라지고 전환 시작도 빨라졌다

### 미구현 사항

이번 빌드는 빌드 5에서 나온 버그와 래그돌 구조 개편에 시간을 크게 썼고, 아래 항목은 **다음 빌드로 이월**한다.

| 항목 | 계획 내용 | 상태 |
| :---- | :---- | :---- |
| **튜토리얼** | 별도 튜토리얼 맵에서 조작 → 본부 → 현장 한 사이클을 안내 | 구현했으나 **이번 빌드에는 미포함** (미머지) |
| **구역 스캔 아이템** | 맵의 일정 영역을 스캔해 범인 유무를 알려주는 본부 설치형 아이템 | 미착수 — **빌드 5에서 이월된 항목이 재이월** |
| **NPC 스캔 카드 정리** | 스캔 카드 위치를 옮기고 이름만 남긴다 | 미착수 — 다음 빌드 |
| **개인 자금 전용 구매 아이템** | 개인 자금으로만 사는 물건 (소비처 신설) | 미착수 — 다음 빌드 |

- 부분 구현: **개인 자금은 잔액을 보는 화면이 없다** — 정산 화면과 약탈 창에서만 금액이 보이고 소비처도 아직 없다.
- 부분 구현: **번역** — 서버가 네트워크로 실어 보내는 안내 문구(토스트 계열)는 여전히 서버 언어 그대로 나온다.

## 2\. 플레이 테스트 결과 (발견 이슈)

### 이슈 A — 호스트가 죽은 뒤 클라가 이탈하면 라운드가 끝나지 않는다

- **증상:** 마지막으로 멀쩡했던 사람이 세션에서 나가면 전멸 판정이 돌지 않아 라운드가 진행 중으로 남는다. 제한시간 무제한 설정에서는 영영 끝나지 않는다.

---

### 이슈 B — 감옥 안에서 눕힌 동료를 밖으로 꺼내지 못한다

- **증상:** 감옥 안에 눕힌 동료를 데리고 나가려 해도 나가기 순간이동이 운반체를 함께 옮기지 않아, 몸이 감옥 안에 남는다.

---

### 이슈 C — 감옥에서 반출한 시체가 굳어서 안 끌린다

- **증상:** 감옥에서 반출한 시체가 그대로 굳어, 밧줄을 놨다 다시 잡아야 움직인다.

---

### 이슈 D — 시체를 끌던 중 대상이 세션에서 나가면 운반자가 멈춘다

- **증상:** 플레이어 시체를 끌고 가던 중 그 플레이어가 세션에서 나가면, 끌고 있던 사람이 그 자리에서 움직이지 못한다.

---

### 이슈 E — 여러 명이 묶은 NPC를 한 명이 데리고 나가면 남의 밧줄이 끊어지지 않는다

- **증상:** 감옥에서 줄다리기로 함께 묶은 NPC를 한 사람이 데리고 나갈 때, 다른 참가자 쪽 밧줄이 끊어지지 않고 남는다.

---

### 이슈 F — 도주형 NPC에게 진압봉이 가끔 빗나간다

- **증상:** 도망치는 NPC를 조준해 때렸는데 판정이 나지 않는다. 임팩트가 0.3초 지연되는 동안 대상이 이동해, 크로스헤어가 약속한 시점과 판정 시점이 어긋난다.

---

### 이슈 G — 클라에서 차량이 잘게 떤다

- **증상:** 상시 교통 차량이 클라이언트 화면에서 미세하게 떨린다. 네트워크 스터터 수정 이후에도 렌더 보간이 복제 값을 오염시켜 남아 있다.

---

### 이슈 H — 상점·게임 씬 진입 시 로봇이 기본색으로 먼저 뜬다

- **증상:** 씬에 들어간 직후 로봇이 잠깐 기본색으로 보이고 그 뒤에 커스터마이징 색이 입혀진다.
