# 빌드 6 빌드 노트 (초안)

---

## 시작 방법 (세션 접속)

1. 게임 실행 → **로그인 관문**에서 UGS 익명 인증으로 로그인한다. 한 번 넘으면 **다음 실행부터는 관문을 건너뛴다**. 계정을 연동해 두면 **다른 기기에서도 같은 닉네임으로 접속**된다. 화면 언어는 설정 창에서 **한국어 / English** 중 고른다 (즉시 반영)
2. 관문을 넘으면 **세션 화면** — 여기서 닉네임을 편집한다. 저장된 판이 있으면 **`이어하기`** 로 그 라운드부터 시작한다. 저장된 판이 없으면 눌렀을 때 그 사유가 화면에 뜬다
3. **호스트**: `세션 만들기 (Create)` → 생성된 Join 코드를 팀원에게 공유
4. **참가자**: Join 코드 입력 → `코드로 참가 (Join)`. **빌드 버전이 다르면 연결 승인 단계에서 거절**되고 로비를 거치지 않고 타이틀에 남는다
5. **로비** — 접속자 목록(신분증 카드)에서 서로의 초상화·닉네임·방장 상태를 확인한다. 여기서 **감정표현 휠 8칸**과 **로봇 색(머리·상체·하체)** 을 미리 구성해 둘 수 있고, 둘 다 계정에 저장돼 다음 실행에도 유지된다. 호스트가 `시작`을 누르면 게임 루프 시작 (상점으로 이동)

## 게임 진행

1. **상점 (경찰서 실내)** — 팀 정산금으로 아이템을 구매한다. 소지형(스캐너·밧줄·부활 키트 등)과 **설치형**(신호 해석기·유치장 사이렌 버튼)을 팔고, 구매품은 팀 소유로 등록되어 **다음 라운드부터 본부 택배 지점으로 배달**된다. **호스트는 이번 라운드에 갈 맵을 고른다** — 맵 선택 콘솔에 **항공뷰 그림과 그 맵의 NPC 수**가 함께 뜬다. 호스트가 `출동 게이트`에 E를 누르면 고른 맵으로 출발
2. **게임 맵** — 화면이 걷히면 전원이 준비 완료 상태가 될 때까지 대기한 뒤 라운드가 시작된다 (NPC 스폰 → 진범 배정 → 수배 리스트 게시). 기본 지급품(스캐너·밧줄·진압봉)은 게임 씬 진입 시 지급되고, 구매품은 본부 택배 지점에 놓인다
3. **라운드 진행** — 제한시간 안에 목표 금액만큼 벌어들인다. 목표 금액은 라운드가 지날수록 오른다. 진행도는 *지금 감옥에 잡아둔 대상들의 현상금의 합*이다. 탈옥하거나 반출하면 진행도도 줄어든다. 진행도는 **본부 내 게시판**에서 볼 수 있다
4. **날씨는 라운드가 시작될 때 하나로 정해져 라운드 내내 이어진다** — 맑음/안개/눈/비·낙뢰 중 하나. 라운드가 올라갈수록 맑음이 나올 확률이 낮아진다
5. **검거 판정 장소는 감옥** — 이번 빌드에서 **감옥이 본부 별동으로 합쳐졌다.** 무력화한 대상을 밧줄로 묶어 감옥까지 끌고 간 뒤 **문 옆 판정 버튼에 E**를 누르면 검거/오검거 판정이 나고 통과한 대상만 감옥 안으로 들어간다. **죽은 대상(시체)도 같은 경로**이며, 사망 그 자체로는 아무것도 판정되지 않는다
6. **수배 조건을 본다** — 진범마다 `생사 불문` / `생포 필수` 조건이 붙고 수배 리스트에 표시된다. 생사 불문 대상을 시체로 인계하면 현상금이 깎이고, **생포 필수 대상을 사살하면 보상이 0**이다
7. 목표를 채우면 **본부의 라운드 종료 버튼이 활성화**된다. 팀이 원할 때 눌러 끝내거나, 더 벌고 싶으면 제한시간까지 계속 수사한다 (안 눌러도 목표를 넘겨 있으면 성공)
8. 라운드가 끝나면 정산 화면을 거쳐 다시 상점으로 복귀 — 세션이 유지된 채 다음 라운드로 이어짐. 정산 화면은 **결과 / 팀 자금 / 내 몫 / 칭호 4줄**이고, 전원이 확인을 누르면 바로 복귀한다. 라운드를 성공하면 그 시점의 판이 **자동 저장**된다

## 조작 방법

> **이번 빌드에서 바뀐 키가 있다** — 인벤토리 `Tab` → **`I`**, 약탈 `E` → **`R`**, `Tab`은 **팀 상황판(홀드)** 이 됐다.

| 입력 | 동작 |
| :---- | :---- |
| WASD / 방향키 | 이동 |
| 마우스 | 시점 회전 |
| 마우스 좌클릭 | 아이템 사용 / **사망 중에는 관전 대상 전환** |
| Left Shift | 달리기 |
| Left Ctrl | 앉기 |
| Space | 점프 |
| E | 상호작용, **쓰러진 동료 일으키기(손을 댄 채 유지)**, 밧줄 풀기 — **아무것도 겨냥하지 않은 E는 끌고 있는 대상 전원을 푼다** |
| **R** | **쓰러진 동료 뒤지기(약탈)** |
| 마우스 휠 | 아이템 슬롯 전환 |
| 1 · 2 · 3 | 아이템 슬롯 직접 선택 |
| G | 장착 아이템 버리기 |
| **I** | **인벤토리** |
| **Tab (홀드)** | **팀 상황판 — 동료의 얼굴·이름·체력·상태 + 이번 라운드 수배 몽타주** |
| T (홀드) | 감정표현 휠 — 홀드한 채 마우스로 조준해 고른다 (구성은 로비에서) |
| V (홀드) | 무전 (Push-to-Talk) |
| M | 마이크 음소거 토글 |
| ESC | 일시정지 패널 — 설정 창(감도·음량·언어·**시점 부드러움·시야각·화면 흔들림·속도 비네트**), 나가기 확인창, 메인 메뉴 복귀 |

> 조준한 대상에는 **`[E] 문 열기`** 처럼 눌러야 할 키가 뜬다. 지금 쓸 수 없는 대상이면 그 사유가 같이 뜬다.

## 아이템 사용법

| 아이템 | 설명 |
| :---- | :---- |
| 밧줄 | 무력화된 대상에게만 좌클릭으로 사용, E로 풀기. 이미 묶여서 끌려가는 NPC에 **좌클릭 한 번으로 합류**(줄다리기) 가능. **시체도 묶어 끌 수 있다** |
| 진압봉 | 타격 가능 (동료도 같은 데미지) |
| 스캐너 | NPC 정보 확인 — 겨냥해 좌클릭 한 번에 즉시 판독. 대상은 그 자리에서 반응한다 |
| 테이저건 | 피격 시 즉시 기절 |
| 부활 키트 | **완전히 사망한** 동료를 겨냥해 그 자리에서 즉시 일으킨다 (소모품). **유예 중(다운)인 동료는 키트 없이 E로 일으킨다** |
| 신호 해석기 | 모든 플레이어에게 텍스트 전달 |
| 사이렌 | 탈옥 이벤트 NPC를 원격으로 제지 |

## 핵심 플레이 루프

1. 외형 필터링 이후 스캐너로 NPC의 정보를 확인하여 몽타주와 비교
2. 범인이면 타격하여 밧줄로 체포 — **수배 조건이 `생포 필수`면 죽이면 안 된다**
3. 체포한 범인을 데려와서 본부에 붙은 감옥 별동의 판정 버튼을 누르면 판정

## 구현된 기능

> 지난 빌드(주간 빌드 1\~5)에서 이미 있던 기능과, 이번 빌드(주간 빌드 6)에 추가된 기능을 나눠 표기.

### 지난 빌드(빌드 1\~5)에서 구현된 것

**네트워크 / 세션 / 계정**

- UGS 익명 로그인, Relay 기반 세션 생성·코드 참가 (최대 6인), Vivox 음성 채팅(V 홀드 무전 + 근접 음성), 마이크 음소거 토글
- 타이틀 → 로비 → 상점 ↔ 게임 맵 루프, 씬 전환 로딩 화면, 전원 준비 완료 게이트, ESC 일시정지 패널·나가기 확인창
- 로비 신분증 카드 명단·세션 입퇴장 알림, 닉네임 영속 저장, 계정 연동, 세션 나가기와 로그아웃 분리
- 한국어(ko-KR)·영어(en) 2개 로케일, 설정 창 언어 드롭다운
- 라운드 성공 시 자동 세이브 / 실패 시 삭제, 타이틀 `이어하기`

**게임 루프 / 라운드 / 경제**

- 라운드 목표 금액(라운드별 상향 표), 진행도는 유치장 점유 현상금 합, 본부 라운드 종료 버튼, 정산 화면, 팀 공용 자금
- 상점(진열대 조준 → 정보 카드 → E로 구매 → 다음 라운드 본부 택배 배달), 아이템 라운드 종료 시 회수
- 개인 자금 — 수배범을 직접 넣은 사람에게 현상금의 일부가 개인 몫으로
- 수금 진행도 게시판, 비밀 청탁, 호스트의 맵 선택

**현장 (수사 · 검거)**

- 검거 수단은 밧줄 — 무력화된 대상만 묶어 끌고 다닌다. 여러 명 동시 끌기, 무게 이동 페널티, 줄다리기 합류
- 진압봉 근접 타격(아군 오사 포함) + NPC 체력 시스템, 테이저(아군 오사)
- 스캐너(배터리 소모 + 본부 충전, 클릭 한 번에 즉시 판독), 스캔 정보 월드 카드와 미스캔 `??` 마스킹
- 감옥 문 앞 판정 버튼, 검거·오검거 판정 배너, 유치장 수감, 수감자 반출, 검거 시 전원 알림
- 아군 약탈, 소매치기에게 뺏기고 되찾기

**본부 (관제)**

- CCTV, 미니맵, 수배 리스트, 시민 인명부 + 외형 대조, 세력 문양 대조판, 신호 해석기, 제보 전화
- 몽타주 픽셀 포트레이트 — 공개된 축만 그리고 미상 축은 글로 표기

**플레이어 / NPC**

- 시민 FSM(배회/순응/도주/저항/기절/체포/수감/재연행), 외형 무작위화, 기절(체력 20%)과 사망(체력 0) 분리, NPC 래그돌
- 3슬롯 인벤토리, 1인칭 손 뷰모델, 앉기, 점프, 이름표·스피커 아이콘, 감정표현 24종, 관전 카메라
- 플레이어 래그돌, HUD(크로스헤어·아이템 윤곽선·상호작용 라벨), NPC 체력 바

**돌발 이벤트 / 연출**

- 범인 탈옥, 전자기기 먹통, 추격 폭탄, 플레이어 납치, 거리 난동자·나체 난동꾼, 소매치기, 폭주 차량, 날씨 3종
- BGM·효과음, 피격 연출, 공용 토스트 UI, 상호작용 문

### 이번 빌드(빌드 6)에 추가된 것

**플레이어**

- **로봇 색 커스터마이징** — 로비 [커스터마이징] 창에서 **머리·상체·하체**를 각각 색칠할 수 있다.
- **동료를 운반할 때도 무게 페널티** — NPC를 끌 때와 같은 합에 1명당 고정 무게가 얹힌다

**플레이어 — 죽음 유예**

- **HP가 0이 되면 즉시 사망이 아니라 60초 유예(다운)** 로 들어간다.
- **동료가 E로 손을 대고 있으면 키트 없이 맨손으로 일으킨다**
- **유예 중 추가 피해는 즉시 완전 사망.** 완전 사망은 래그돌 + 관전 카메라로 넘어간다.
- 완전 사망한 동료 **부활 키트**로만 살릴 수 있다.

**HUD / UI**

- **조준한 대상에 조작키를 띄운다** — `[E] 문 열기` 형태. 지금 못 쓰는 대상이면 **막힌 사유**가 뜬다.
- **Tab 홀드 팀 상황판** — 동료의 얼굴·이름·체력·상태(생존/납치/기능 정지)와 이번 라운드 수배 몽타주를 한 화면에서 본다.
- **미니맵** — 배경이 빈 사각형이었던 것을 **실제 맵 항공뷰**로 깔았고, **납치범을 빨간 아이콘으로**, **범위가 있는 이벤트는 반투명 원**으로 표시한다.
- **맵 선택 콘솔** — 맵 이름만 있던 콘솔에 **항공뷰 그림과 스폰 NPC 수**를 띄운다

**본부 — 유치장 편입 · 시스템 해킹**

- **본부 실내를 전면 개편하고 유치장을 본부 별동으로 합쳤다** — 감옥이 본부에 붙은 별동이 됐다. **본관에서 철창 너머로 수감자가 보인다**
- **'전자기기 먹통'을 '시스템 해킹'으로** — 12초 자동 복구를 폐기하고 해제 권한을 본부에 넘겼다. **본부 책상의 복구 단말에서 네 자리 코드를 10초 안에 입력**해야 풀린다.
- **라운드가 갈수록 몽타주 화질이 떨어진다** — 표시 단계에서 레이어별로 점점 뭉개져(128→64→32→16px) 난이도가 오른다

**현상금 / 검거 판정**

- **수배 조건 도입 (#766)** — 진범마다 **`생사 불문`(Dead Or Alive) / `생포 필수`(Alive Only)** 가 배정되고 본부 수배 리스트에 표시된다. 생사 불문 대상을 시체로 인계하면 **현상금이 감액**되고, 생포 필수 대상을 사살하면 **보상 0 + 조건 불충족 배너**가 뜬다. 위조범·난동꾼은 조건 없이 전액이다

**NPC**

- **방치된 NPC는 체력이 서서히 회복된다** — 마지막 피해로부터 20초 무피해면 초당 2HP씩 최대치까지. 오래 방치된 NPC는 진압봉 페이싱이 처음부터 다시 간다

**래그돌 — 시체가 모두에게 같게 보인다**

- **플레이어 및 NPC 래그돌 적용** — NPC와 플레이어가 죽으면 관절이 흐느적거리는 래그돌 상태가 된다.

**돌발 이벤트 / 환경**

- **폭주 차량이 상시 교통이 됐다** — 도로에 차가 계속 지나간다. **닿으면 즉사이고 시민도 같은 피해를 받는다** — 환경이 죽인 시민은 오검거로 세지 않는다.
- **날씨는 라운드마다 하나만 뽑아 라운드 내내 지속된다** — 돌발 이벤트 추첨에서 빼고 `맑음 + 3종` 4택으로 옮겼다. **라운드가 오를수록 맑음 확률이 낮아진다**

**네트워크 / 세션**

- **버전이 다른 클라이언트를 연결 승인 단계에서 거절한다** — 참가 후 스스로 물러나던 방식이라 로비가 잠깐 보였다 사라지던 것을 없앴고, 검사 코드가 없는 구버전 클라도 막는다
- **세션이 끊기면 사유를 토스트로 알린다** — 호스트 이탈 / 연결 끊김 / 세션 삭제를 구분해 타이틀 복귀 후 표시한다
- **호스트와 클라가 같이 로딩 화면으로 넘어간다** — 서버가 덮기 직전에 전환을 예고한다. 호스트가 1초쯤 먼저 뜨던 것이 사라지고 전환 시작도 빨라졌다
