## 조작 방법

| 입력 | 동작 |
| :---- | :---- |
| WASD / 방향키 | 이동 |
| 마우스 | 시점 회전 |
| 마우스 좌클릭 | 아이템 사용 / **사망 중에는 관전 대상 전환** |
| Left Shift | 달리기 |
| Left Ctrl | 앉기 |
| Space | 점프 |
| E | 상호작용, **쓰러진 동료 일으키기(손을 댄 채 유지)**, 밧줄 풀기 — **아무것도 겨냥하지 않은 E는 끌고 있는 대상 전원을 푼다**. **부활 키트를 소지하고 있으면 본인이 다운·사망 중에도 E를 홀드해 스스로 일으킬 수 있다** |
| R | 쓰러진 동료 뒤지기(약탈) |
| 마우스 휠 | 아이템 슬롯 전환 |
| **1 · 2 · 3 · 4 · 5** | **아이템 슬롯 직접 선택** |
| G | 장착 아이템 버리기 |
| I | 인벤토리 |
| Tab (홀드) | 팀 상황판 — 동료의 얼굴·이름·체력·상태 + 이번 라운드 수배 몽타주 |
| T (홀드) | 감정표현 휠 — 홀드한 채 마우스로 조준해 고른다 (구성은 로비에서) |
| V (홀드) | 무전 (Push-to-Talk) |
| M | 마이크 음소거 토글 |
| ESC | 일시정지 패널 |

## 아이템 사용법

| 아이템 | 설명 |
| :---- | :---- |
| 밧줄 | 무력화된 대상에게만 좌클릭으로 사용, E로 풀기. 이미 묶여서 끌려가는 NPC에 좌클릭 한 번으로 합류(줄다리기) 가능. 시체도 묶어 끌 수 있다 |
| 진압봉 | 타격 가능 (동료도 같은 데미지). **이번 빌드에서 판정 폭을 부채꼴로 넓히고, 빗나가면 화면에 알려준다** — 도주형 상대에게 임팩트 지연과 크로스헤어 시점이 어긋나 헛스윙하던 문제를 이렇게 손봤다 |
| 스캐너 | NPC 정보 확인 — 겨냥해 좌클릭 한 번에 즉시 판독. 대상은 그 자리에서 반응한다 |
| 테이저건 | 피격 시 즉시 기절 |
| 부활 키트 | 완전히 사망한 동료를 겨냥해 그 자리에서 즉시 일으킨다 (소모품). 유예 중(다운)인 동료는 키트 없이 E로 일으킨다. **신규 — 소지하고 있으면 동료 없이도 E 홀드로 스스로 일으킬 수 있다(자가 부활)** |
| 신호 해석기 | 모든 플레이어에게 텍스트 전달 |
| 사이렌 | 탈옥 이벤트 NPC를 원격으로 제지 |
| **구역 스캔 (신규)** | **영구형(쿨타임 60초, 소모 없음).** 사용 지점 기준 반경 20m를 즉발 판정해 **진범 유무만** 초록/빨강 링으로 보여준다 — 위치·인원수는 알려주지 않고, 근처 플레이어 전원이 같은 링을 본다. 전자기기 먹통(시스템 해킹) 중에는 사용할 수 없다 |
| **회복 아이템 (힐팩, 신규)** | 소모형. 사용하면 본인 체력을 즉시 회복한다. 살아 있는 상태에서 HP를 되돌리는 첫 수단이며, 부활 키트와는 별도 아이템이다 |
| **거대 뿅망치 (신규)** | 개그용 근접 무기 — 평타는 체력을 1만 깎지만, 명중마다 낮은 확률(기본 1%)로 즉사급 데미지(9999)가 대신 들어간다. **동료도 대상**이라 대박이 터지면 건강한 동료는 다운, 이미 다운된 동료는 확인사살로 완전 사망한다. 확률 판정은 서버 전용 |
| **홈런 진압봉 (배트, 신규)** | 데미지를 주지 않는 대신, 맞은 대상을 타격 방향으로 **래그돌로 날려 보낸다**. NPC와 동료 모두 대상이며, 죽이지 않으므로 밧줄 검거 흐름과 충돌하지 않는다 |

## 핵심 플레이 루프

1. 외형 필터링 이후 스캐너로 NPC의 정보를 확인하여 몽타주와 비교
2. 범인이면 타격하여 밧줄로 체포 — **수배 조건이 `생포 필수`면 죽이면 안 된다**
3. 체포한 범인을 데려와서 본부에 붙은 감옥 별동의 판정 버튼을 누르면 판정

## 구현된 기능

> 지난 빌드(주간 빌드 1~6)에서 이미 있던 기능과, 이번 빌드(주간 빌드 7)에 추가된 기능을 나눠 표기.

### 지난 빌드(빌드 1~6)에서 구현된 것

**네트워크 / 세션 / 계정**

- UGS 익명 로그인, Relay 기반 세션 생성·코드 참가 (최대 6인), Vivox 음성 채팅(V 홀드 무전 + 근접 음성), 마이크 음소거 토글
- 타이틀 → 로비 → 상점 ↔ 게임 맵 루프, 씬 전환 로딩 화면, 전원 준비 완료 게이트, ESC 일시정지 패널·나가기 확인창
- 로비 신분증 카드 명단·세션 입퇴장 알림, 닉네임 영속 저장, 계정 연동, 세션 나가기와 로그아웃 분리
- 한국어(ko-KR)·영어(en) 2개 로케일, 설정 창 언어 드롭다운
- 라운드 성공 시 자동 세이브 / 실패 시 삭제, 타이틀 `이어하기`
- 로봇 색 커스터마이징(머리·상체·하체), 버전이 다른 클라이언트 연결 승인 단계 거절, 세션 끊김 사유 토스트, 호스트·클라 동시 로딩 전환

**게임 루프 / 라운드 / 경제**

- 라운드 목표 금액(라운드별 상향 표), 진행도는 유치장 점유 현상금 합, 본부 라운드 종료 버튼, 정산 화면, 팀 공용 자금
- 상점(진열대 조준 → 정보 카드 → E로 구매 → 다음 라운드 본부 택배 배달), 아이템 라운드 종료 시 회수
- 개인 자금 — 수배범을 직접 넣은 사람에게 현상금의 일부가 개인 몫으로
- 수금 진행도 게시판, 비밀 청탁, 호스트의 맵 선택
- 수배 조건(생사 불문/생포 필수), 본부가 유치장 별동과 합쳐짐, 몽타주 화질 저하(라운드 상승 시)

**현장 (수사 · 검거)**

- 검거 수단은 밧줄 — 무력화된 대상만 묶어 끌고 다닌다. 여러 명 동시 끌기, 무게 이동 페널티(동료 운반 포함), 줄다리기 합류
- 진압봉 근접 타격(아군 오사 포함) + NPC 체력 시스템, 테이저(아군 오사)
- 스캐너(배터리 소모 + 본부 충전, 클릭 한 번에 즉시 판독), 스캔 정보 월드 카드와 미스캔 `??` 마스킹
- 감옥 문 앞 판정 버튼, 검거·오검거 판정 배너, 유치장 수감, 수감자 반출, 검거 시 전원 알림
- 아군 약탈, 소매치기에게 뺏기고 되찾기
- 플레이어 죽음 유예(다운 60초) → 완전 사망(래그돌 + 관전 카메라), 부활 키트로만 완전 사망 소생

**본부 (관제)**

- CCTV(적외선/야시경 모드 포함), 미니맵(항공뷰, 납치범 표시, 이벤트 반경 표시), 수배 리스트, 시민 인명부 + 외형 대조, 세력 문양 대조판, 신호 해석기, 제보 전화
- 몽타주 픽셀 포트레이트 — 공개된 축만 그리고 미상 축은 글로 표기
- Tab 홀드 팀 상황판, 조준 대상 조작키 안내(막힌 사유 포함)

**플레이어 / NPC**

- 시민 FSM(배회/순응/도주/저항/기절/체포/수감/재연행), 외형 무작위화, 기절(체력 20%)과 사망(체력 0) 분리, NPC 래그돌
- 5슬롯 인벤토리, 1인칭 손 뷰모델, 앉기, 점프, 이름표·스피커 아이콘, 감정표현 24종, 관전 카메라
- 플레이어 래그돌, HUD(크로스헤어·아이템 윤곽선·상호작용 라벨), NPC 체력 바
- 방치된 NPC 체력 서서히 회복

**돌발 이벤트 / 연출**

- 범인 탈옥, 전자기기 먹통(시스템 해킹), 추격 폭탄, 플레이어 납치, 소매치기, 폭주 차량(상시 교통), 날씨 4종(맑음/안개/눈/비·낙뢰)
- BGM·효과음, 피격 연출, 공용 토스트 UI, 상호작용 문

### 이번 빌드(빌드 7)에 추가된 것

**튜토리얼**

- **신규 플레이어용 1인 전용 튜토리얼 맵 추가 (#663)** — 타이틀 [튜토리얼] 버튼으로 진입, 첫 접속 시 한 번 권유. 핵심 루프를 축소해 한 번 완주시키는 것이 목적이며, 튜토리얼 중에는 플레이어가 쓰러지지 않는다

**아이템 확장**

- **구역 스캔** — 영구형·쿨타임 60초. 반경 20m 안 진범 유무를 초록/빨강 링으로만 알려준다
- **체력 회복 아이템(힐팩)** — HP를 회복시킨다
- **부활 키트 자가 부활** — 소지하고 있으면 동료 없이도 E 홀드로 스스로 일으킨다
- **거대 뿅망치** — 낮은 확률로 즉사급 데미지가 터지는 개그 무기
- **홈런 진압봉** — 데미지 대신 대상을 래그돌로 날려 보낸다
- **치장 토큰·뽑기 자판기** — 라운드 클리어 시 전원 1개 지급, 상점 자판기에서 커스터마이징에 사용하는 치장품을 무작위로 뽑는다
- **상점 진열 카탈로그화** — 진열이 매 라운드 랜덤 재추첨으로 바뀌고, 주문은 카탈로그로 처리
- **구매 내역·잔여 소모품 표시** — 주문창 탭과 본부 게시판에서 확인 가능

**맵 / 환경**

- **맵을 더 밀도 있게** — 골목·막다른 길을 늘렸다
- **CCTV 적외선(야시경) 모드** — 콘솔 버튼으로 켜고 끄는 녹색 톤 모드. 어두운 골목·실내의 사각을 본부의 조작 선택으로 걷어냈다
- **UFO 빔 상시화** — 맵 상공에 UFO가 늘 떠 있고 빔도 늘 켜져 있다. 빔에 일정 시간 머무르면 흡입되어 시체가 회수 불가능한 곳으로 사라진다. 지붕 밑은 안전하다
- 본부 밖 배달 지점 신설 — 배달 드론이 보급 상자를 실외에 내려놓는다

**돌발 이벤트 / NPC**

- **세력 소탕** — 유치장 수감자의 세력이 복수대 N명을 보내 현장 플레이어 한 명을 쫓아가 때린다.
- NPC 공격 사운드 추가

**진행 차단성 버그 수정**

- 호스트 사후 클라 이탈 시 전멸 판정이 안 돌던 문제
- 감옥 안에 눕힌 동료를 밖으로 못 꺼내던 문제
- 감옥에서 반출한 시체가 굳어서 다시 잡아야 움직이던 문제
- 여러 명이 묶은 NPC를 한 명이 데려나가면 나머지 참가자의 밧줄이 안 끊기던 문제
- 시체를 끌던 중 대상이 세션에서 나가면 운반자가 멈추던 문제 
- 수감자가 감옥 밖을 배회하던 버그
- 맨홀 납치 사망자가 부활·회수 대상에 잘못 걸리던 문제
- 사망 중 동료 시점 순환 관전이 안 되던 회귀 버그 

**UI 전반**

- 임시 UI를 전부 정식 UI로 교체
