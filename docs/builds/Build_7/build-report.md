## 1. 이번 빌드 요약

**튜토리얼**

- **신규 플레이어용 1인 전용 튜토리얼 맵 추가 (#663)** — 타이틀 [튜토리얼] 버튼으로 진입, 첫 접속 시 한 번 권유. 핵심 루프를 축소해 한 번 완주시키는 것이 목적이며, 튜토리얼 중에는 플레이어가 쓰러지지 않는다. **빌드 6에서 "구현했으나 미포함(미머지)"였던 항목이 이번 빌드에 정식 편입됐다**

**아이템 확장**

- **구역 스캔(신규)** — 영구형·쿨타임 60초, 소모 없음. 반경 20m 안 진범 유무만 초록/빨강 링으로 표시(위치·인원수는 비공개), 전자기기 먹통(시스템 해킹) 중에는 사용 불가. 
- **회복 아이템(힐팩, 신규)** — 소모형. 생존 상태에서 HP를 되돌리는 첫 수단이며 부활 키트와는 별도 아이템
- **부활 키트 자가 부활(신규)** — 소지하고 있으면 동료 없이도 E 홀드로 스스로 일으킬 수 있다
- **거대 뿅망치(신규)** — 개그용 근접 무기. 평타는 체력 1 감소, 명중마다 낮은 확률(기본 1%)로 즉사급 데미지(9999)가 대신 들어간다.
- **홈런 진압봉/배트(신규)** — 데미지 대신 맞은 대상을 타격 방향으로 래그돌로 날려 보낸다. NPC·동료 모두 대상, 죽이지 않으므로 밧줄 검거 흐름과 충돌하지 않음
- **치장 토큰·뽑기 자판기(신규)** — 라운드 클리어 시 전원 1개 지급, 상점 자판기에서 커스터마이징용 치장품을 무작위로 뽑는다
- **상점 진열 카탈로그화** — 진열이 매 라운드 랜덤 재추첨으로 바뀌고, 주문은 카탈로그로 처리
- **구매 내역·잔여 소모품 표시** — 주문창 탭과 본부 게시판에서 확인 가능
