## 1\. 폴리싱 및 버그 수정

### 폴리싱
- 구역 스캔 결과 시각적 피드백 개선
- NPC가 NavMesh가 없는 곳에 떨어질 경우에 날아가기 직전 위치로 텔레포트 하는 로직 개선
- 차에 치여 죽었을 때, 날아가는 래그돌 적용
- NPC 체력이 40%일 때에 기절, 0%일 때에 사망을 플레이어와 동일하게 0% 기절, 한번 더 타격 시에 사망으로 수정
- 게임 결과 화면 수정

### 버그 수정

- 수배 리스트 UI가 규격을 벗어나는 버그
- 아이템 배달될 때, 구역 스캔 아이템이 바닥에 껴서 안주워지는 버그
- NPC를 밧줄로 묶으니까 바닥으로 빠지는 버그
- 게임에서 강제 종료하여 나가면 정리가 제대로 안되어 기존 세션에 재접속이 안되는 버그 수정
