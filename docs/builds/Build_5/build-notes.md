# 빌드 5 빌드 노트

---

## 시작 방법 (세션 접속)

1. 게임 실행 → **로그인 관문**에서 UGS 익명 인증으로 로그인한다. 한 번 넘으면 **다음 실행부터는 관문을 건너뛴다**. 계정을 연동해 두면 **다른 기기에서도 같은 닉네임으로 접속**된다. 화면 언어는 설정 창에서 **한국어 / English** 중 고른다 (즉시 반영)  
2. 관문을 넘으면 **세션 화면** — 여기서 닉네임을 편집한다. 저장된 판이 있으면 **`이어하기`** 버튼이 함께 뜬다  
3. **호스트**: `세션 만들기 (Create)` → 생성된 Join 코드를 팀원에게 공유  
4. **참가자**: Join 코드 입력 → `코드로 참가 (Join)`. **빌드 버전이 다르면 참가가 거절**되고 타이틀로 돌아온다  
5. **로비** — 접속자 목록에서 서로의 초상·닉네임·방장·발화 상태를 확인한다. 여기서 **감정표현 휠 8칸**을 미리 구성해 둘 수 있다. 호스트가 `시작`을 누르면 게임 루프 시작 (상점으로 이동)

## 게임 진행

1. **상점 (경찰서 실내)** — 팀 정산금으로 아이템을 구매한다. 소지형(스캐너·밧줄·부활 키트 등)과 **설치형**(신호 해석기·유치장 사이렌 버튼)을 팔고, 구매품은 팀 소유로 등록되어 **다음 라운드부터 본부 택배 지점으로 배달**된다. **호스트는 이번 라운드에 갈 맵을 고른다** (안 고르면 기본 맵). 호스트가 `출동 게이트`에 E를 누르면 고른 맵으로 출발  
2. **게임 맵** — 로딩 화면이 걷히면 **참가자 전원이 준비를 보고할 때까지 대기**한 뒤 라운드가 시작된다 (NPC 스폰 → 진범 배정 → 수배 리스트 게시). 기본 지급품(스캐너·밧줄·진압봉)은 게임 씬 진입 시 지급되고, 구매품은 본부 택배 지점에 놓인다  
3. **라운드 진행** — 제한시간 안에 목표 금액만큼 벌어들인다. **목표 금액은 라운드가 지날수록 오른다.** 진행도는 *지금 감옥에 잡아둔 대상들의 현상금의 합이다.* 탈옥하거나 반출하면 진행도도 줄어든다. 진행도는 **본부 내 게시판**에서 볼 수 있다  
4. **검거 판정 장소는 감옥** — 무력화한 대상을 밧줄로 묶어 감옥까지 끌고 간 뒤, **문 옆 판정 버튼에 E**를 누르면 검거/오검거 판정이 나고 통과한 대상만 감옥 안으로 들어간다. **죽은 대상(시체)도 같은 경로다** — 감옥에 넣어야 계상된다  
5. 목표를 채우면 **본부의 라운드 종료 버튼이 활성화**된다. 팀이 원할 때 눌러 끝내거나, 더 벌고 싶으면 제한시간까지 계속 수사한다 (안 눌러도 목표를 넘겨 있으면 성공)  
6. 라운드가 끝나면 정산 화면을 거쳐 다시 상점으로 복귀 — 세션이 유지된 채 다음 라운드로 이어짐. 정산 화면에는 **팀 자금과 내 개인 몫이 함께** 표시되고, **전원이 확인을 누르면 카운트다운 없이 바로 복귀**한다. 라운드를 성공하면 그 시점의 판이 **자동 저장**된다

## 조작 방법

| 입력 | 동작 |
| :---- | :---- |
| WASD / 방향키 | 이동 |
| 마우스 | 시점 회전 |
| 마우스 좌클릭 | 아이템 사용 / **사망 중에는 관전 대상 전환** |

| Left Ctrl | 앉기 |
| Space | 점프 |
| E | 상호작용, 밧줄 풀기, **쓰러진 동료 약탈** |

| Tab | 인벤토리 |
| **T (홀드)** | **감정표현 휠 — 홀드한 채 마우스로 조준해 고른다 (구성은 로비에서)** |

| M | 마이크 음소거 토글 |

## 아이템 사용법

| 아이템 | 설명 |
| :---- | :---- |
| 밧줄 | 무력화된 대상에게만 좌클릭으로 사용, E로 풀기. 이미 묶여서 끌려가는 NPC에 **좌클릭 한 번으로 합류**(줄다리기) 가능. **시체도 묶어 끌 수 있다** |
| 진압봉 | 타격 가능 (동료도 같은 데미지) |
| 스캐너 | NPC 정보 확인 — **겨냥해 좌클릭 한 번에 즉시 판독**(홀드 없음). 대상은 그 자리에서 반응한다 |
| 테이저건 | 피격 시 즉시 기절 |
| **부활 키트** | **기능 정지된 동료를 겨냥해 그 자리에서 즉시 일으킨다 (소모품)** |
| 신호 해석기 | 모든 플레이어에게 텍스트 전달 |
| 사이렌 | 탈옥 이벤트 NPC를 원격으로 제지 |

## 핵심 플레이 루프

1. 본부에서만 볼 수 있는 몽타주를 보고 현장에 무전으로 알림  
2. 현장은 외형 필터링 이후 스캐너로 NPC의 정보를 확인  
3. 범인이면 타격하여 밧줄로 체포 (체력 0은 **사망**이므로 시체를 끌게 된다)  
4. 체포한 범인을 데려와서 본부 옆의 감옥 컨테이너의 판정 버튼을 누르면 판정

## 구현된 기능

> 지난 빌드(주간 빌드 1\~4)에서 이미 있던 기능과, 이번 빌드(주간 빌드 5)에 추가된 기능을 나눠 표기.

### 지난 빌드(빌드 1\~4)에서 구현된 것

**네트워크 / 세션 / 계정**

- UGS 익명 로그인, Relay 기반 세션 생성·코드 참가 (최대 6인), Vivox 음성 채팅(V 홀드 무전 \+ 근접 음성), 마이크 음소거 토글  
- 타이틀 → 로비 → 상점 ↔ 게임 맵 루프, 씬 전환 로딩 화면, 전원 준비 완료 게이트, ESC 일시정지 패널·나가기 확인창  
- 로비 접속자 목록, 닉네임 영속 저장, 계정 연동, 세션 나가기와 로그아웃 분리  
- 한국어(ko-KR)·영어(en) 2개 로케일, 설정 창 언어 드롭다운

**게임 루프 / 라운드 / 경제**

- 라운드 목표 \= 목표 금액, 진행도는 유치장 점유 현상금 합, 본부 라운드 종료 버튼, 정산 화면, 팀 공용 자금  
- 상점(진열대 조준 → 정보 카드 → E로 구매 → 다음 라운드 본부 택배 배달), 아이템 라운드 종료 시 회수  
- 개인 자금 — 수배범을 직접 넣은 사람에게 현상금의 일부가 개인 몫으로. 잔액은 본인만 본다  
- 수금 진행도 게시판, 비밀 청탁(전화 받은 사람 개인 의뢰)

**현장 (수사 · 검거)**

- 검거 수단은 밧줄 — 무력화된 대상만 묶어 끌고 다닌다. 여러 명 동시 끌기, 무게 이동 페널티, 줄다리기 합류  
- 진압봉 근접 타격(아군 오사 포함) \+ NPC 체력 시스템, 테이저(아군 오사)  
- 스캐너(배터리 소모 \+ 본부 충전), 스캔 정보 월드 카드와 미스캔 `??` 마스킹  
- 반응 트리거는 스캔·피격 — 의심받으면 도주, 순응형은 맞으면 도주/저항  
- 감옥 문 앞 판정 버튼, 검거·오검거 판정 배너, 유치장 수감, 수감자 반출  
- 감옥 간판·감옥 CCTV 채널·본부 유치장 경보등, 유치장 사이렌 버튼

**본부 (관제)**

- CCTV(화면 전환·전원 버튼, 미니맵 마커, 채널 라벨), 수배 리스트, 시민 인명부 \+ 외형 대조 6축, 세력 문양 대조판, 신호 해석기  
- 제보 전화 — 받으면 예비 용의자 1명이 수배 리스트에 공개

**플레이어 / NPC**

- 시민 FSM(배회/순응/도주/저항/기절/체포/수감/재연행), 외형 무작위화  
- 3슬롯 인벤토리, 1인칭 손 뷰모델, 앉기, 점프, 이름표·스피커 아이콘, 3인칭 장착 아이템 동기화  
- HP 0이면 곧바로 기능 정지(Die) \+ 본부 부활 장치, 플레이어 래그돌, HUD(크로스헤어·아이템 윤곽선·상호작용 라벨), NPC 체력 바

**돌발 이벤트**

- 범인 탈옥, 전자기기 먹통, 추격 폭탄, 플레이어 납치, 거리 난동자·나체 난동꾼

**연출 / 사운드 / UI**

- BGM(씬 전환 페이드) \+ 효과음(발소리·스캔·검거 판정 등), 피격 연출(먼지·히트마커·비네트·화면 흔들림)  
- 공용 토스트 UI, 신호 해석기 TMP 입력창, 상호작용 문

### 이번 빌드(빌드 5)에 추가된 것

**맵 — 상점 맵 · 사이버펑크 맵 제작**

- **사이버펑크 맵을 새로 제작** — 20 × 12칸(100 × 60m, 플레이 영역 90 × 50m) 규모의 도시.

**게임 루프 — 라운드별 할당량 · 맵 선택**

- **라운드가 지날수록 목표 금액이 오른다** — 1\~10라운드 값을 표(`RoundQuotaTable`) 한 곳에서 관리하고, 표에 정의된 마지막 라운드를 넘어가면 그 값이 유지된다  
- **맵을 골라서 라운드를 진행한다** — 호스트가 **상점에서 다음 라운드에 갈 맵을 고르고**, 출동하면 그 맵으로 간다.

**플레이어**

- **감정표현 24종** — T 홀드로 휠을 조준해 고른다. 휠 8칸 구성은 로비에서 정한다

**NPC — 기절과 죽음을 분리했다**

- **체력 0이 기절이 아니라 사망이다.** 체력이 20%면 기절, 0이면 사망으로 바뀌었고 동일하게 검거 판정을 받는다  
- **죽은 대상은 시체로 남고, 밧줄로 끌어 감옥에 넣어야 검거로 계상된다** — 감옥에 정착한 시체는 그 자리에 고정된다  
- **사망·기절한 NPC는 래그돌로 무너진다** — 관절에 힘이 빠진 채 쓰러지고, 그 상태로 끌려간다. NPC 4종 프리팹에 리그를 배선했다  
- 시체도 **비밀 청탁의 반출 대상**이 된다

**아이템**

- **부활 키트** — 기능 정지된 동료를 **현장에서 즉시** 일으킨다.

**본부 — 몽타주를 그림으로 보여준다**

- **몽타주에 그림을 추가했다.** 무채색 두상 위에 **공개된 축만** 얹어 그린 픽셀 포트레이트다  
- **말하지 않은 축은 그리지 않는다** — 빈자리가 '없음'이 아니라 '미상'으로 읽히고, **미상인 축은 그림 대신 글로** 따로 적는다  
- 본부가 그림을 보고 **자기 말로 무전에 옮기는 것**까지가 플레이어의 몫이라는 점은 그대로다

**세이브 / 로드**

- **라운드를 성공하면 그 시점의 판이 자동 저장된다** — 라운드 번호·팀 자금·고른 맵·팀 구매 목록·개인 지갑을 클라우드에 올린다  
- **타이틀의 `이어하기`로 물려받아 시작한다** — 세션을 새로 만들어도 저장된 라운드부터 이어진다  
- **라운드를 실패하면 세이브가 지워진다** — 게임오버가 판의 끝이라는 규칙은 유지된다

**관전**

- **쓰러지면 내 시체를 도는 3인칭 카메라로 바뀐다** — 죽은 뒤 1인칭에 갇혀 있던 문제(빌드 4 임시 처리)가 해소됐다  
- **좌클릭으로 동료 시점을 순환한다** — 살아 있는 동료들을 한 방향으로 돌며 본다

**돌발 이벤트 — 소매치기 · 폭주 차량 · 날씨**

- **소매치기** — 현장 플레이어에게 붙어 소지품을 훔쳐 달아난다. **털린 사람에게 알림이 뜨고**, 놓친 뒤에 잡아도 물건을 되찾는다. 무력화되면 훔친 물건을 그 자리에 떨군다.  
- **폭주 차량** — 도로에 세워 둔 차 넉 대 중 하나가 **일직선 경로에 들어온 사람에게 경고음을 낸 뒤 급발진**한다. 차가 다가오는 것을 소리로 먼저 알 수 있고, 차에 타격당하면 즉시 사망한다.  
- **날씨 3종**  
  - **안개** — 시야가 제한된다  
  - **눈** — 오래 내리면 **빙판이 누적되고 그친 뒤 서서히 녹는다**. 빙판으로 인해 플레이어의 이동이 미끄러워진다.  
  - **비·낙뢰** — 떨어질 지점을 예고한 뒤 낙하한다. 맞으면 **피해 또는 이동속도 버프** 중 하나다

**로비 화면**

- **접속자 명단을 신분증 카드로 갈아 끼웠다** — 초상·닉네임·방장·음성 상태가 한 카드에 들어간다  
- **입퇴장 알림을 세션 전 씬으로** 넓혔다 — 로비뿐 아니라 상점·게임 맵에서도 누가 들어오고 나갔는지 뜬다

**그 외**

- **스캔은 좌클릭 한 번에 즉시 판독된다** — 3초 홀드 채널링이 사라졌다. 줄다리기 합류도 클릭 한 번이다. 대신 **스캔한 대상은 그 자리에서 반응**한다  
- **아군 약탈** — 기능 정지된 동료를 겨냥해 E를 누르면 소지품과 개인 자금이 뜬다. 여는 것만으로는 넘어오지 않고 칸을 눌러야 가져간다. 털린 사람에게는 알림이 뜬다  
- **검거 알림이 전원에게 방송된다** — 대상 이름과 함께 뜨고, 알림 종류가 색으로 갈린다  
- **오검거 페널티 제거** — 지금 오검거의 결과는 **오검거 횟수 집계**뿐이다

## 임시 처리

- **맵 선택 정책 미정**: 수단만 마련됐다 — 라운드마다 맵이 바뀌어야 하는지(지금은 안 고르면 그대로 간다), 고르는 주체를 호스트 단독으로 둘지 투표로 갈지는 미정  
- **라운드 할당량 값은 조정 중**: 라운드마다 오르는 축은 확정이지만 값은 플레이 테스트로 다듬는다. **인원 수(3\~6인)별 조절은 아직 손대지 않았다**  
- **세이브 범위는 세션 단위 한 벌**: 라운드 성공 시 자동 저장 / 실패 시 삭제. 개인 자금으로 산 소지품은 아직 담기지 않는다(소비처가 없어서)  
- **개인 자금은 잔액을 보는 화면이 없다**: 정산 화면과 약탈 창에서만 금액이 보인다. 소비처도 아직 없다  
- **번역 미적용 구간**: 서버가 네트워크로 실어 보내는 안내 문구(토스트 계열)는 아직 서버 언어 그대로 나온다 — 별도 이슈로 분리해 둔 상태  
- **로딩 화면**: **페이드 인은 없다**
- **NPC 제자리 뛰는 현상**: 맵의 NavMesh에 빈틈이 일부 있어서 제자리 걸음 현상 있을 수 있음
