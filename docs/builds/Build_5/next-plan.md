# 4팀 빌드 5 다음 빌드 계획

## 다음 빌드 목표

- 이번 빌드에서 밀린 **콘텐츠(아이템·현상금)** 를 마무리하고,
  \+ **온보딩·조작 안내**(튜토리얼·조작키 표시)를 갖춰 처음 들어온 사람도 게임을 이해할 수 있게 한다
  \+ **콘텐츠 확장**(외형 커스터마이징·맵 추가·구매 아이템)과 **네트워크 안정성**(세션 이탈 처리)
  \+ 플레이 테스트에서 나온 **진행 차단성 버그**를 정리한다

---

## 이월 항목 (빌드 5에서 넘어옴)

버그 수정 및 개선 사항을 우선 처리하느라 이번 빌드에서 착수하지 못한 항목이다.

### 아이템 추가

- 맵의 일정 영역을 스캔해서 범인이 있는지 없는지를 알려주는 **아이템**

### 현상금 시스템 수정

- 기절한 NPC와 죽은 NPC의 현상금을 다르게 적용
  - 빌드 5에서 **기절과 사망 상태 분리가 끝났으므로** 이제 차등을 걸 수 있다

### NPC 이동 폴리싱 — 남은 부분

- 장애물에 부딪혀서 제자리 걸음을 하지 않고 미끄러지듯이 지나갈 수 있게 수정

## 온보딩 / 조작 안내 (신규)

### 튜토리얼 (#663)

- 신규 플레이어가 조작과 핵심 루프를 익히는 튜토리얼
- 가르칠 것: 조작 / 현장의 "대조 → 무력화 → 유치장 인계" / 본부의 수배 리스트·CCTV / 오검거의 대가

### 조준한 대상에 조작키 표시 (#664)

- `[E] 문 열기`처럼 **키 + 동작**을 띄운다. 키는 실제 바인딩에서 읽는다

## 조작감 / UI 개선

### 시점 스무딩 재조정 (#665)

- 화면이 너무 부드럽게 따라와 멀미가 난다
- 시점 입력 스무딩(`PlayerLook.m_lookSmoothing`) 개선

### NPC 스캔 카드 위치·정보 요약 (#666)

- 카드에 **이름만** 남기고, 표시 위치를 옮긴다

### 미니맵

- 실제 맵을 **위에서 항공뷰로 렌더링**해서 보여준다
- **돌발 이벤트 발생 지역을 빨간 원으로 표시한다**

## 콘텐츠 추가

### 캐릭터 외형 커스터마이징

- 플레이어가 자기 외형 색깔을 변경 및 치장품 추가
- 로비에서 고르고, **로컬 저장**(계정 단위)으로 다음 실행에도 유지한다

### 개인 자금으로 구매 가능한 아이템

- 지금은 라운드 공용 자금으로만 산다 — **개인 자금으로 사는 아이템**을 따로 둔다
- 개인 자금은 이미 소매치기·아군 약탈로 뺏고 뺏기는 대상이다. 쓸 곳이 생기면 그 이벤트들의 무게가 살아난다
