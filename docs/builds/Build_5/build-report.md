# 빌드 5 빌드 결과 보고서 (초안)

---

## 1\. 이번 빌드 요약

**진행 구조 / 난이도**

- **라운드가 지날수록 목표 할당량이 오르는 난이도 커브** 적용 (정산이 해당 라운드 할당량을 기준으로 계산)
- **세션 세이브/로드** — 호스트가 진행 중인 판을 저장하고, 타이틀에서 **이어하기**로 복원

**맵**

- **사이버펑크 테마 맵 추가**
- **상점에서 호스트가 다음 라운드 맵을 선택**

**NPC**

- **기절과 사망 상태 분리** — 체력 0은 기절이 아니라 **사망** 처리, 시체는 래그돌로 남고 밧줄로 끌어 유치장까지 운반 가능
- 기절한 NPC도 래그돌로 무너지고, 깨어나면 기상 모션으로 복귀
- **이동 폴리싱** — NPC 재탐색(repath)을 한 곳에서 개체별 위상 오프셋, 도주 지점에 도달 가능성 검사 추가(제자리 달리기 원인), 추격 로직 정리(멈칫거림·공전 제거)

**돌발 이벤트 추가**

- **소매치기** — 플레이어 소지품/개인 자금을 훔치고, 무력화되면 훔친 물건을 그 자리에 떨군다
- **차량 급발진(교통사고)** — 맵에 배치된 차량이 폭주해 대상을 친다
- **날씨 이벤트 3종** — 비·낙뢰(지점 예고 낙하), 눈(빙판 누적·미끄러짐), 안개. 실내는 강수에서 제외
- 돌발 이벤트 발생 시 **전원 화면에 알림 토스트**

**플레이어 표현 / 편의**

- **감정표현 24종** — T 홀드 휠 UI, 머리 위 이모지, 로비에서 휠 8칸 구성
- **부활 키트** — 기능 정지된 동료를 현장에서 즉시 일으키는 아이템
- **아군 약탈** — 쓰러진 동료의 소지품·개인 자금 빼앗기
- **사망 중 관전** — 내 시체를 도는 3인칭 카메라 + 동료 시점 순환(무전 차단)

**UI / 세션**

- **로그인 관문**과 세션 화면 정비 (한 번 통과하면 다음 실행부터 건너뜀)
- **로비 대기 화면을 신분증 명단으로 교체**, 입·퇴장 알림
- **검거 성립 시 전 플레이어에게 알림**(대상 이름 포함)
- **몽타주를 글자에서 그림(포트레이트)으로** 전환, 외형 어휘 확장(머리 38종·수염 6종·안경 7종)
- **버전이 다른 빌드의 세션 참가 차단**
- 로딩 화면 개편, 정산 확인 단계 정리, 오검거 페널티 발동 중지(집계만 유지)

### 미구현 사항

버그 수정 및 개선 사항을 우선 처리하느라 시간이 부족해, 아래 두 항목은 **다음 빌드로 이월**한다.

| 항목 | 계획 내용 | 상태 |
| :---- | :---- | :---- |
| **아이템 추가** | 맵의 일정 영역을 스캔해 범인 유무를 알려주는 **본부 설치형 아이템** | 미착수 — 다음 빌드 |
| **현상금 시스템 수정** | 기절한 NPC와 죽은 NPC의 **현상금 차등 적용** | 미착수 — 다음 빌드 |

- 부분 구현: **세이브/로드**는 세션 저장(호스트 권한)까지만 구현했고, **로컬 저장**(커스터마이징 외형, 조작·오디오 설정)은 다음 빌드로 넘긴다.

## 2\. 빌드 4 지적 이슈 처리 결과

| 이슈 | 내용 | 처리 | 비고 |
| :---- | :---- | :---- | :---- |
| A | 납치당한 플레이어가 폭탄에 휘말리면 몸이 굳고 맵 밖으로 나가진다 | **해결** | 폭발 사망 시 납치범이 대상을 놓아주도록 정리 조건에 추가. 폭발에 휘말리면 밧줄에서도 손을 떼고, 끌려가는 동안 받은 넉백이 나중에 터지지 않게 함. |
| B | 외형 정보가 실제 모델과 어긋난다 (대머리인데 머리색이 붙는다) | **해결** | 빌드 4 기간 내 처리. 이후 외형 어휘 확장 작업에서 머리색이 팩을 넘어가면 적용되지 않던 문제도 함께 수정. |
| C | 맵 가장자리에서 기절한 NPC가 굳어 회수되지 않는다 | **해결** | NavMesh 밖에서 굳은 NPC를 서버가 스스로 회수하도록 처리. 맵에 NavMesh 볼륨을 추가하고 재베이크. |
| D | 납치범에게 테이저가 통하지 않는다 | **해결** | 테이저로도 납치범을 떼어낼 수 있도록 격퇴 트리거를 피해량 기준에서 무력화 기준으로 변경. 이슈 A와 묶어서 처리. |

## 3\. 플레이 테스트 결과 (발견 이슈)

### 이슈 A — 로그인이 정상적으로 되지 않는다

- **증상:** 타이틀의 로그인 관문에서 로그인이 실패하거나 통과하지 못하고 멈추는 경우가 있다. 게임 진입 자체가 막힌다.

---

### 이슈 B — 라운드 클리어 후 상점 씬으로 이동할 때 플레이어가 맵 밖으로 튕겨나간다

- **증상:** 라운드가 끝나고 상점 씬으로 넘어가는 순간, 플레이어가 정해진 위치가 아니라 맵 바깥으로 튕겨 나간다.

---

### 이슈 C — 부활할 때 플레이어가 맵 밖으로 튕겨나간다

- **증상:** 기능 정지 상태에서 부활하는 순간, 플레이어가 부활 지점이 아니라 맵 바깥으로 튕겨 나간다.

---

### 이슈 D — 밧줄로 묶었는데도 검거 판정이 되지 않는다

- **증상:** NPC를 밧줄로 묶어 제압한 상태인데도 검거가 성립하지 않아, 유치장까지 데려가도 처리되지 않는다.

---

### 이슈 E — 밧줄로 끄는 NPC가 땅에 박혀 잘 끌려오지 않는다

- **증상:** 밧줄로 묶은 NPC를 끌고 갈 때 몸이 지면에 박힌 것처럼 걸려, 끌리다 멈추거나 끌려오는 속도가 크게 느려진다.

---

### 이슈 F — NPC가 플레이어가 접근할 수 없는 지역에 스폰된다

- **증상:** 라운드 시작 시 NPC가 건물 안쪽이나 막힌 구역 등 플레이어가 도달할 수 없는 위치에 스폰되는 경우가 있다.

---

### 이슈 G — NavMesh 빈틈에서 NPC가 제자리 걸음을 한다

- **증상:** 맵의 특정 지점에서 NPC가 이동 모션만 재생한 채 앞으로 나아가지 못하고 제자리에서 걷는다. 맵 곳곳에서 간헐적으로 발생한다.

---

### 이슈 H — 래그돌로 전환될 때 몸이 수직으로 튀어오른다

- **증상:** 플레이어나 NPC가 쓰러져 래그돌로 전환되는 순간, 몸이 위로 한 번 솟았다가 떨어진다.
